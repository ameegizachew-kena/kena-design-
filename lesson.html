PIXELLAB TOOLS

🛠️ Tool Tokkoon Tokkoon Baradhu

Suuraa tool tokkoon tokkoo cuqaasuun guddisuu dandeessa.

1

📝 Text

Text jechuun barruu ykn jecha design kee irratti barreessuuf fayyadu.

Fakkeenyaaf: KENA DESIGN, maqaa namaa, title, quote ykn beeksisa barreessuu dandeessa.

Text erga dabaltanii booda size, position, rotation fi style isaa jijjiiruu dandeessa.

📍 Bakka: PixelLab → Add (+) → Text
2

🧊 3D Text

3D Text jechuun barruu kee akka dheerina fi depth qabu fakkeessuuf fayyada.

Logo, title fi poster irratti text nama hawwatu hojjechuuf gaarii dha.

Text filadhu → Text effects keessaa 3D ykn perspective fakkaatu fayyadami.

📍 Bakka: Text filadhu → Text Effects → 3D
3

✨ Text Effects

Text Effects keessatti Shadow, Inner Shadow, Stroke, Background, Reflection, Emboss, Mask fi effects biroo argatta.

Text plain ta'e gara text professionalitti jijjiiruuf fayyada.

📍 Bakka: Text filadhu → Effects
4

🔤 Font

Font jechuun bifa qubee barruu keetii.

Font adda addaa keessaa filachuun poster kee professional ykn modern gochuu dandeessa.

PixelLab keessatti fonts hedduu qaba. Font ofii kees import gochuu dandeessa.

📍 Bakka: Text → Font
5

🎨 Color

Color text ykn object kee halluu ittiin kennituudha.

Simple color qofa osoo hin taane gradient, radial gradient fi image texture illee fayyadamuu dandeessa.

📍 Bakka: Text → Color
6

😀 Stickers

Stickers jechuun emoji, mallattoo fi graphics xixiqqoo design irratti dabaluudha.

Poster, YouTube thumbnail fi social media design keessatti nama hawwata.

📍 Bakka: Add (+) → Stickers
7

🖼️ Image Import

Image import jechuun gallery kee keessaa suuraa gara PixelLab keessa galchuu dha.

Suuraa namaa, logo, product ykn background gara project keessa galchuu dandeessa.

📍 Bakka: Add (+) → From Gallery / Image
8

✏️ Draw

Draw tool'n harkaan drawing ykn mallattoo mataa keetii hojjechuuf fayyada.

Line, shape ykn freehand drawing hojjechuu dandeessa.

📍 Bakka: Add (+) → Draw
9

🌈 Background

Background jechuun duubbee project kee.

Halluu tokko, gradient ykn image akka background godhachuu dandeessa.

📍 Bakka: Background → Color / Gradient / Image
10

💾 Save Project

Project save gochuun hojii kee gara boodaatti deebitee itti fufuuf si gargaara.

Project format keessatti yoo save goote, text fi layers gara fuulduraatti edit gochuu dandeessa.

📍 Bakka: Menu → Save as Project
11

✂️ Background Removal

Background removal'n background suuraa keessaa baasuun object ykn nama qofa hambisa.

Logo, product photo fi poster irratti baay'ee fayyada.

📍 Bakka: Image/Object → Remove Background
12

📐 Perspective / Warp

Perspective editing'n suuraa ykn text gara bifa angle adda addaatti jijjiira.

3D fakkaatu, billboard fakkaatu ykn design realistic gochuuf fayyada.

📍 Bakka: Object → Perspective / related transform tools
13

🌟 Image Effects

Image Effects suuraa kee miidhagsuuf fi mood adda addaa uumuuf fayyada.

Vignette, stripes, hue, saturation fi effects biroo fayyadamuun suuraa fooyyessuu dandeessa.

📍 Bakka: Image → Effects
14

📚 Layers

Layers jechuun object tokko tokko addaan addaan to'achuuf fayyadu.

Text, image, sticker fi shape gara fuulduraa ykn duubaatti dabarsuu dandeessa.

Layer tokko hide, lock ykn edit gochuu dandeessa.

📍 Bakka: Top toolbar → Layers icon
15

📤 Export / Save Image

Export'n hojii xumurte gara image akka PNG ykn JPGtti baasuuf fayyada.

Social media, WhatsApp, YouTube thumbnail, poster ykn printing irratti fayyadamuuf image godha.

📍 Bakka: Menu → Export / Save as Image
