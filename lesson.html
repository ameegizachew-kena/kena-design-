2️⃣ NOTE BAL'AA

PixelLab maalif fayyada?

PixelLab app mobile irratti design graphics hojjechuuf gargaarudha. Text, 3D Text, shapes, stickers, images, drawing, backgrounds fi effects fayyadamuun poster, social-media design, logo fakkaataa, quote, thumbnail fi hojiiwwan graphics biroo qopheessuu dandeessa.

Lesson kana keessatti wanti guddaan ati hubachuu qabdu: tool tokko tokko maal akka ta'e qofa osoo hin taane, maaliif akka fayyadu fi yeroo kamiitti akka fayyadamu beekuudha.

🛠️ TOOLS

Tools Tokkoon Tokkoon

Tool hunda keessatti maal akka ta'e, maaliif akka fayyadu, bakka itti argamu fi akkamitti akka fayyadamu ilaali.

01

✍️ Text

Text tool'n barruu haaraa gara canvas keetti dabala.

Maaliif fayyada?

Maqaa poster, title, subtitle, quote, phone number, social-media message fi odeeffannoo biroo barreessuuf.

Bakka itti argamu:

Gara gubbaa mallattoo + tuqi → Text.

Akkamitti:
+ → Text → barruu barreessi → OK → barruu sana tuqi → size fi position sirreessi.
02

🔤 Font

Font jechuun boca barruu ittiin barreeffamuudha.

Maaliif fayyada?

Title tokko jabaa, elegant, modern ykn professional akka fakkaatu gochuuf.

Bakka itti argamu:

Text filadhu → menu text keessaa Font.

Akkamitti:
Text filadhu → Font → font tokko filadhu → OK → bu'aa isaa ilaali.
03

🎨 Color

Color tool'n halluu text jijjiira.

Maaliif fayyada?

Text fi background gidduu contrast uumuuf. Fakkeenyaaf background dukkanaa irratti text adii ykn magariisaa fayyadamuun dubbifamuu isaa fooyyeessa.

Bakka itti argamu:

Text filadhu → Color.

Akkamitti:
Color → Simple Color ykn Gradient → halluu filadhu → OK.
04

✨ Shadow

Shadow text duuba gaaddisa uuma.

Maaliif fayyada?

Text background irraa adda akka ba'u fi depth akka qabaatu gochuuf.

Bakka itti argamu:

Text filadhu → Shadow.

Akkamitti:
Shadow ON → color → blur → opacity → distance sirreessi.
05

3️⃣ 3D Text

3D Text'n barruu akka dheerina fi depth qabu fakkeessa.

Maaliif fayyada?

Poster title guddaa, YouTube thumbnail fi design attention namaa hawwatuuf.

Bakka itti argamu:

Text filadhu → Text Effects/3D options.

Akkamitti:
Text → 3D effect → depth fi angle sirreessi → shadow itti dabali.
06

⚡ Text Effects

Text Effects keessatti Shadow, Inner Shadow, Stroke, Background, Reflection, Emboss, Mask fi effects biroo argamu.

Maaliif fayyada?

Text salphaa gara text design fakkaatutti jijjiiruuf.

Bakka itti argamu:

Text filadhu → Effects.

Akkamitti:
Effect filadhu → ON → settings isaa jijjiiri → OK.
07

⭐ Stickers

Stickers, emojis fi shapes gara design keetti dabaluuf.

Maaliif fayyada?

Poster kee decoration fi visual interest akka qabaatuuf.

Bakka itti argamu:

+ → Sticker.

Akkamitti:
Sticker filadhu → tuqi → size, rotation fi position sirreessi.
08

🖼️ Import Image

Suuraa Gallery keessaa gara PixelLab galchuuf.

Maaliif fayyada?

Logo, photo, product image ykn sticker mataa keetii fayyadamuuf.

Bakka itti argamu:

+ → From Gallery / Image.

Akkamitti:
Gallery → suuraa filadhu → OK → resize fi move godhi.
09

✏️ Draw

Draw tool'n harkaan sarara ykn mallattoo kaasuuf.

Maaliif fayyada?

Decoration, line, arrow, signature ykn shape mataa keetii uumuuf.

Bakka itti argamu:

+ → Draw.

Akkamitti:
Brush size → color → canvas irratti harkaan kaasi.
10

🌈 Background

Background'n duubbee canvas jijjiira.

Maaliif fayyada?

Design kee theme tokko akka qabaatuuf.

Bakka itti argamu:

Background menu.

Akkamitti:
Color, Gradient ykn Image filadhu → background kaa'i.
11

✂️ Remove Background

Suuraa tokko irraa background haquuf.

Maaliif fayyada?

Nama, product ykn object tokko background irraa adda baasuuf.

Bakka itti argamu:

Image filadhu → Remove Background.

Akkamitti:
Image filadhu → Remove Background → transparent result ilaali → sirreessi → save.
12

↗️ Perspective

Perspective/warp'n text ykn image akka gara kallattii adda addaatti jallatu godha.

Maaliif fayyada?

Billboard, road sign, box, screen ykn design realistic fakkeessuuf.

Bakka itti argamu:

Object filadhu → Perspective/Warp option.

Akkamitti:
Corners harkisi → angle jijjiiri → OK.
13

☰ Layers

Layers'n object hunda addaan addaan to'achuuf.

Maaliif fayyada?

Text tokko gara fuulduraatti, image tokko gara duubaatti dabarsuuf.

Bakka itti argamu:

Mallattoo Layers gara gubbaa.

Akkamitti:
Layers bani → object filadhu → hide, lock, delete, copy ykn order jijjiiri.
14

💾 Save Project

Hojii kee project godhanii kuusuuf.

Maaliif fayyada?

Booda deebitee text, color, image fi layers edit gochuuf.

Bakka itti argamu:

Mallattoo Save.

Akkamitti:
Save → Save as Project → maqaa kaa'i → Save.
15

📤 Export

Project kee gara JPG ykn PNG fakkaatutti baasuuf.

Maaliif fayyada?

Poster kee Gallery keessatti kuusuu ykn social media irratti qooduuuf.

Bakka itti argamu:

Save/Export → Save as Image.

Akkamitti:
Format → PNG/JPG → Quality → Dimensions → Save to Gallery.
