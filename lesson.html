🎬 1. Video Lesson

📚 2. Lesson Kana Keessatti Maal Baratta?

Lesson kana keessatti PixelLab fayyadamuun font haaraa akkamitti galchuu, font filachuu, text barreessuu, halluu jijjiiruu, size sirreessuu fi text kee poster keessatti sirnaan qindeessuu baratta.

💡 Kaayyoo: Dhumarratti ati font tokko ofii keetii galchitee, PixelLab keessatti text professional ta'e qopheessuu dandeessa.

🔤 3. Font Maali?

Font jechuun bifa qubee ittiin barruun mul'atuudha. Fakkeenyaaf qubeen tokko font adda addaatiin yeroo barreeffamu bifa adda addaa qaba.

🎯 Maaliif Font barbaachisa?

  • Design kee bareedaa taasisa.
  • Ergaa kee dubbistootaaf salphisa.
  • Poster professional fakkeessa.
  • Brand kee adda baasuu danda'a.
  • Social media design keessatti nama hawwata.

🔠 4. Gosoota Font

1️⃣ Serif

Qubee xumura isaa irratti mallattoo xiqqoo qabu. Kitaaba fi hojii formal keessatti baay'ee fayyada.

2️⃣ Sans Serif

Qubee qulqulluu fi salphaa. Logo, website, social media fi poster keessatti gaarii dha.

3️⃣ Script

Qubee harkaan barreeffame fakkaatu. Invitation fi design artistic keessatti fayyada.

4️⃣ Display

Mata-duree guddaa fi poster irratti nama hawwatuuf qophaa'e.

📁 5. TTF fi OTF

Font download gootu yeroo baay'ee faayila TTF ykn OTF argatta.

.TTF = TrueType Font
.OTF = OpenType Font

PixelLab keessatti lamaan isaanii keessaa font supported ta'e fayyadamuun ni danda'ama.

📱 6. Font Haaraa PixelLab Keessatti Galchuu

  1. Font barbaadde internet irraa download godhi.
  2. File Manager bani.
  3. Faayila .ttf ykn .otf barbaadi.
  4. PixelLab bani.
  5. Text irratti cuqaasi.
  6. Font option barbaadi.
  7. My Fonts ykn Add Font filadhu.
  8. Faayila font kee filadhu.
  9. Import godhi.
  10. Font haaraa text kee irratti hojiirra oolchi.

🧪 8. Akkaataa Hojii Irra Oolchuu

Step 1 — Font Filadhu

Font tokko qofa filadhu. Design kee irratti font baay'ee fayyadamuun dubbisa nama rakkisuu danda'a.

Step 2 — Text Galchi

PixelLab bani → Text → Add Text. Ergaa poster kee barreessi.

Step 3 — Font Jijjiiri

Text kee filadhu → Font → My Fonts. Sana booda font ati galchite filadhu.

Step 4 — Color

Background dukkanaa yoo ta'e text ifaa fayyadami. Background ifaa yoo ta'e text dukkanaa fayyadami.

Step 5 — Size

Mata-duree guddaa godhi. Barruu ibsaa ammoo xiqqoo godhi.

💡 Seera design: Mata-duree, subtitle fi body text gidduutti garaagarummaa ifa ta'e qabaachuun design kee dubbifamuu salphisa.
