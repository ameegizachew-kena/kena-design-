LESSON 1 — PIXELLAB

PixelLab Sirriitti Baradhu

Lesson kana keessatti PixelLab fayyadamuun Text, Font, Color, 3D Text, Text Effects, Stickers, Image, Draw, Background, Layers, Background Removal, Perspective, Image Effects, Save Project fi Export tartiiba tartiibaan baranna.

📱 PixelLab Google Play Irraa Buufadhu ➡️ Google Play → Install → Open

1. 📱 PixelLab Maal?

PixelLab jechuun app Android irratti suuraa fi graphic design hojjechuuf gargaarudha. App kana keessatti text stylish, 3D text, shapes, stickers, drawing, background fi image editing hojjechuu dandeessa.

Google Play listing PixelLab keessatti Text, 3D Text, text effects, fonts, stickers, image import, drawing, background, project saving, background removal, perspective editing, image effects fi export tarreeffamaniiru.

➡️ Bakka itti argamu: App erga bantee booda fuula hojii guddaa fi toolbar PixelLab argita.

2. 📥 PixelLab Install Gochuu

1️⃣ Google Play bani.
2️⃣ Search keessatti PixelLab barreessi.
3️⃣ PixelLab kan App Holdings jedhu filadhu.
4️⃣ Install cuqaasi.
5️⃣ Erga install ta'ee booda Open cuqaasi.
➡️ PixelLab Google Play Bani
💡 Hubachiisa: Lesson kun PixelLab kan Google Play irratti argamu (com.imaginstudio.imagetools.pixellab) irratti hundaa'a. Google Play irratti appichi 19 January 2026 irratti update godhameera. 1

3. 🖥️ PixelLab Interface Ilaali

Kun fakkeenya interface PixelLab ti. Suuraa kana cuqaasi — guddatee screen guutuu irratti ni mul'ata.

🔍 Suuraa cuqaasi → guddisi → × tuqi → cufi
➡️ Toolbar: tools gara garaa itti argattu.
➡️ Canvas: bakka design itti hojjetu.
➡️ Text controls: Text filattee booda options isaa ittiin jijjiirtu.

4. ✏️ TEXT — Barreessuu

Text jechuun barruu gara design keessa galchuudha. Kun tool PixelLab keessatti yeroo baay'ee itti fayyadamtu keessaa tokko.

🎯 Maalif fayyada?

  • Maqaa barreessuuf.
  • Title barreessuuf.
  • Poster hojjechuuf.
  • YouTube thumbnail irratti barruu galchuuf.
  • Logo-style text hojjechuuf.
  • Quote fi slogan barreessuuf.
➡️ Bakka itti argamu: Toolbar keessatti mallattoo T / Text barbaadi.

🛠️ Akkamitti itti fayyadamta?

1️⃣ Text/T cuqaasi.
2️⃣ Barruu kee barreessi.
3️⃣ OK ykn ✓ cuqaasi.
4️⃣ Text kee filadhu.
5️⃣ Guddina, bakka fi angle isaa sirreessi.
🎯 Fakkeenya: “KENA DESIGN” barreessi. Ergasii font, color, shadow fi stroke itti dabali.

5. 🔤 FONT — Boca Qubee

Font jechuun bifa qubee text kee jijjiiruudha. PixelLab keessatti fonts hedduu keessaa filachuu dandeessa. Akkasumas font ofii kee fayyadamuun ni danda'ama. 2

➡️ Bakka itti argamu: Text filadhu → Font filadhu.

🛠️ Tarkaanfii

1️⃣ Text filadhu.
2️⃣ Font banu.
3️⃣ Font tokko filadhu.
4️⃣ ✓/Apply godhi.
🎯 Fakkeenya: Title poster tokkoof font jabaa fayyadami. Text xiqqaaf font dubbifamuu salphaa filadhu.

6. 🎨 COLOR — Halluu

Color tool'n text ykn object kee halluu barbaaddeen gochuuf fayyada. PixelLab keessatti simple color qofa osoo hin taane linear gradient, radial gradient fi image texture illee text irratti fayyadamuun ni danda'ama. 3

➡️ Bakka itti argamu: Text filadhu → Color filadhu.

🛠️ Akkamitti?

1️⃣ Text filadhu.
2️⃣ Color bani.
3️⃣ Halluu filadhu.
4️⃣ Gradient barbaadde yoo ta'e gradient filadhu.
5️⃣ ✓ cuqaasi.
🎯 Fakkeenya: Background dukkanaa irratti white + green text yaali.

7. 🧊 3D TEXT

3D Text jechuun text kee akka dheerina ykn depth qabu fakkeessuudha.

➡️ Bakka itti argamu: Text filadhu → 3D Text option barbaadi.

🎯 Maalif?

  • Poster irratti title guddaa gochuuf.
  • Logo-style design gochuuf.
  • Text adda baasuu fi nama hawwatuuf.

🛠️ Tarkaanfii

1️⃣ Text filadhu.
2️⃣ 3D Text bani.
3️⃣ Depth/angle sirreessi.
4️⃣ Preview ilaali.
5️⃣ ✓ Apply godhi.

8. ✨ TEXT EFFECTS

Text Effects text kee akka ifa, jabaa fi professional fakkaatu gochuuf gargaaru.

➡️ Bakka itti argamu: Text filadhu → Effects / Style.
  • 🌑 Shadow — text duuba gaaddisa kaa'a.
  • 🔲 Stroke — text marsaa daangaa kaa'a.
  • 🎨 Background — text duuba background kaa'a.
  • ✨ Reflection — calaqqee text fakkeessa.
  • 🪨 Emboss — text akka ol-ka'e fakkeessa.
  • 🎭 Mask — text effect addaa uumuuf.
🎯 Fakkeenya: Text adii + Stroke gurraacha + Shadow xiqqoo. Kun thumbnail irratti text akka ifatti mul'atu godha.

9. 🏷️ STICKERS & SHAPES

Stickers, emojis fi shapes design keessatti decoration fi mallattoo dabaluuf gargaaru. 4

➡️ Bakka itti argamu: Toolbar/menu keessaa Stickers / Shapes barbaadi.

🛠️ Tarkaanfii

1️⃣ Sticker ykn Shape filadhu.
2️⃣ Canvas irratti kaa'i.
3️⃣ Guddina isaa jijjiiri.
4️⃣ Color fi position isaa sirreessi.

10. 🖼️ IMPORT IMAGE

Gallery irraa suuraa gara PixelLab keessa galchuuf fayyada. Suuraa lama ykn isaa ol walitti makuunis ni danda'ama. 5

➡️ Bakka itti argamu: Toolbar → Image / Import → Gallery.

🛠️ Tarkaanfii

1️⃣ Image/Import filadhu.
2️⃣ Gallery bani.
3️⃣ Suuraa filadhu.
4️⃣ ✓ cuqaasi.
5️⃣ Size fi position sirreessi.
🎯 Fakkeenya: Suuraa nama tokko galchi → background kee kaa'i → text itti dabali → poster godhi.

11. ✍️ DRAW

Draw tool'n pen size fi color filachuun waan barbaadde canvas irratti kaasuu dandeessa. Drawing erga hojjettee booda shape fakkaatee resize, rotate fi shadow itti dabaluun ni danda'ama. 6

➡️ Bakka itti argamu: Toolbar keessaa Draw barbaadi.

🛠️ Tarkaanfii

1️⃣ Draw filadhu.
2️⃣ Brush/pen filadhu.
3️⃣ Size filadhu.
4️⃣ Color filadhu.
5️⃣ Canvas irratti kaasi.

12. 🌄 BACKGROUND

Background jechuun duubbee design keetii. PixelLab keessatti background akka color, gradient ykn image ta'u gochuu dandeessa. 7

➡️ Bakka itti argamu: Menu keessaa Background barbaadi.

🛠️ Fakkeenya

1️⃣ Background bani.
2️⃣ Color filadhu.
3️⃣ Ykn Gradient filadhu.
4️⃣ Ykn Image akka background filadhu.

13. ✂️ REMOVE BACKGROUND

Tool kun suuraa keessaa background balleessuun object ykn nama qofa hambisuuf fayyada. Green screen, blue screen ykn background adii irraa subject adda baasuu keessatti fayyada. 8

➡️ Bakka itti argamu: Image filadhu → editing options keessaa Remove Background ykn background removal option barbaadi.
🎯 Fakkeenya: Suuraa nama tokko background isaa balleessi → background haaraa kaa'i → text fi logo itti dabali.
⚠️ Maqaan menu version/app/device irratti xiqqoo garaagaruu danda'a.

14. 🔄 PERSPECTIVE / WARP

Perspective editing (warp) jechuun suuraa tokko angle addaatiin qindeessuu ykn boca isaa perspective irratti jijjiiruudha. 9

➡️ Bakka itti argamu: Image filadhu → Perspective / Warp option barbaadi.
🎯 Fakkeenya: Monitor screen tokko irratti logo ykn image akka dhugumaan screen keessa jiru fakkeessuuf perspective fayyadami.

15. 🌈 IMAGE EFFECTS

Image Effects suuraa kee fooyyeessuuf fayyadu. Google Play listing keessatti vignette, stripes, hue fi saturation fakkaatan tarreeffamaniiru. 10

➡️ Bakka itti argamu: Image filadhu → Effects / Adjustments.
  • ☀️ Brightness
  • ◐ Contrast
  • 🌈 Saturation
  • 🎨 Hue
  • ⭕ Vignette
  • 〰️ Stripes
  • 🌫️ Blur ykn effects biroo yoo version kee keessatti jiraate
💡 Effect baay'ee cimaa hin godhin. Design professional keessatti effect xiqqoo fi madaalaa fayyadamuun caalaatti bareeda.

16. 🧱 LAYERS / OBJECTS

Yeroo Text, Image, Shape fi Sticker hedduu qabdu, layers/object order isaan qindeessuuf barbaachisa.

➡️ Bakka itti argamu: Toolbar/menu keessaa Layers ykn mallattoo layers barbaadi.

Layers maalif?

  • ⬆️ Object tokko ol siqsiisuuf.
  • ⬇️ Object tokko gadi siqsiisuuf.
  • 👁️ Object dhoksuuf/show gochuuf.
  • 📋 Duplicate gochuuf.
  • 🗑️ Delete gochuuf.
  • 🔒 Object lock gochuuf yoo option jiraate.
🎯 Fakkeenya: Background → Image → Shape → Text → Logo Tartiiba kanaan objects kee qindeessi.

17. 💾 SAVE AS PROJECT

Project akka projectitti save gochuun yeroo biraa deebi'anii gulaaluuf si gargaara. Google Play listing illee “Save as a project” jedhu ni ibsa. 11

➡️ Bakka itti argamu: Menu → Save Project.
1️⃣ Save Project filadhu.
2️⃣ Maqaa project kenni.
3️⃣ Save godhi.
💡 Design xumuraa qofa osoo hin taane project file illee save godhuun gaarii dha.

18. 📤 EXPORT IMAGE

Export jechuun design kee gara image taasisuun gallery keessatti save ykn share gochuudha. PixelLab format ykn resolution adda addaatiin export gochuu danda'a. 12

➡️ Bakka itti argamu: Menu → Export / Save as Image.
1️⃣ Export filadhu.
2️⃣ PNG ykn JPG filadhu.
3️⃣ Resolution/quality sirreessi.
4️⃣ Save/Export cuqaasi.
🎯 Fakkeenya: YouTube Thumbnail → PNG/JPG → Save → Gallery keessatti ilaali.

19. 🔍 PixelLab Toolbar Fakkeenya

Suuraa kana cuqaasi. Toolbar fi layer controls guddifamanii ilaalu dandeessa.

🔍 Suuraa cuqaasi → guddisi → × tuqi
➡️ Gubbaa: Add, Save, Share, Undo, Zoom, Grid fi Layers fakkaatan arguu dandeessa.

➡️ Jala: Text editing fi object options gara garaa arguu dandeessa.

20. 🔤 Font fi Text Options Fakkeenya

Fakkeenya kana keessatti font, 3D text, shadow, stroke, reflection fi line spacing fakkaatan mul'atu.

🔍 Cuqaasi → screenshot guddisi
