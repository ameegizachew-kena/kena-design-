1. 📱 PixelLab jechuun maal?

PixelLab application Android irratti text, suuraa, shape fi wantoota graphic adda addaa fayyadamuun design hojjechuuf gargaarudha.

Graphic Design barachuu jalqabuuf mobile phone irratti PixelLab akka meeshaa practical tokkootti fayyadamuu dandeessa.

2. 🖥️ PixelLab Interface

Video keessatti PixelLab bannee yeroo ilaallu, bakka adda addaa fi buttons/tools garaagaraa argina.

Barataan tokko tokkoon isaanii maal akka hojjetan hubachuu qaba.

💡 Yaadadhu:

Tool tokko osoo hin fayyadamin dura maal akka hojjetu hubachuun barbaachisaa dha.

3. 🛠️ Tools fi Features

① Text Tool

Text barreessuu fi design keessa galchuuf fayyada.

② Font

Akkaataa qubee/text itti mul'atu jijjiiruuf fayyada.

③ Text Size

Text guddisuu ykn xiqqeessuuf fayyada.

④ Text Color

Halluu text jijjiiruuf fayyada.

⑤ Shape

Boca garaagaraa design keessa galchuuf fayyada.

⑥ Image

Suuraa phone keessaa gara projectitti galchuuf fayyada.

⑦ Background

Background design kee jijjiiruuf fayyada.

⑧ Position / Move

Object ykn text bakka barbaaddeetti sochoosuuf fayyada.

⑨ Layers / Objects

Wantoota project keessa jiran adda addaan qindeessuuf si gargaara.

⑩ Save / Export

Design kee akka image tokkootti save ykn export gochuuf fayyada.
