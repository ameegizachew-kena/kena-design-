📘 Lesson 1 — PixelLab Tools and Features

🎯 Kaayyoo Lesson kanaa

Lesson kana booda PixelLab maal akka ta'e, interface isaa, tools isaa fi akkaataa design bu'uuraa itti hojjetan ni baratta.

🎥 Video Lesson

🎨 Graphic Design jechuun maal?

Graphic Design jechuun yaada tokko suuraa, halluu, text, shape fi elements garaagaraa fayyadamuun karaa nama hawwatuun dhiyeessuudha.

📱 PixelLab jechuun maal?

PixelLab application design keessatti text, image, shape, color fi effects fayyadamuuf gargaarudha.

🛠️ Tools fi Features

1. Text Tool

Barreeffama design kee keessa galchuuf fayyadami.

2. Font

Akka barreeffamni kee bareeduuf font sirrii filadhu.

3. Text Size

Text guddaa ykn xiqqaa gochuuf fayyadami.

4. Text Color

Halluu text jijjiiri. Halluun background waliin wal simachuu qaba.

5. Text Style

Bold, italic fi style garaagaraa yaali.

6. Stroke

Text naannoo isaa irratti border/daangaa gochuuf fayyadami.

7. Shadow

Text ykn object irratti shadow dabali.

8. Alignment

Text fi objects bakka sirriitti qindeessuuf fayyadami.

9. Position / Move

Object bakka barbaaddeetti siqsi.

10. Rotate

Text ykn object gara kallattii barbaaddetti naannessi.

11. Opacity

Object ifa ykn dukkanaa'aa gochuuf fayyadami.

12. Shape

Rectangle, circle fi shapes biroo design keessa galchi.

13. Image

Suuraa galchuun design kee keessatti fayyadami.

14. Background

Background halluu ykn suuraa ta'uu danda'a.

15. Objects / Layers

Objects garaagaraa sirriitti qindeessi.

16. Save / Export

Design kee yeroo xumurtu JPG ykn PNG godhii save godhi.

💻 PC irratti

Yoo PC irratti hojjetta ta'e, tools fi principles wal fakkaatan fayyadamuun design hojjechuu dandeessa. Mouse fi keyboard fayyadamuun hojii saffisaa fi sirrii gochuu dandeessa.

📱 Android irratti

Android irratti PixelLab fayyadamuun:

  • Text galchi
  • Font jijjiiri
  • Color sirreessi
  • Image galchi
  • Shape fayyadami
  • Position sirreessi
  • Shadow fi Stroke yaali
  • PNG/JPG godhii save godhi

Amma waan Lesson 1 keessatti baratte fayyadamuun PixelLab irratti poster kee ofii keetiin hojjedhu.

  1. PixelLab bani.

  4. Title tokko barreessi.
  5. Font sirrii filadhu.
  6. Text Size sirreessi.
  7. Text Color jijjiiri.
  8. Shape tokko ykn lama fayyadami.
  9. Suuraa tokko galchi.
  10. Position fi Alignment sirreessi.
  11. Stroke ykn Shadow yaali.
  12. Design kee qulqullinaan qindeessi.
  13. JPG ykn PNG godhii save godhi.

📘 Lesson 2 — Design Principles

🎯 Lesson 2 keessatti maal baratta?

Lesson kana keessatti design bareedaa fi professional ta'e hojjechuuf principles bu'uuraa baratta.

1️⃣ Alignment

Text fi objects bakka sirriitti qindeessi. Elements walitti makamuun design kee hin burjaajessin.

2️⃣ Contrast

Halluuwwan fi text wal irraa adda baafami. Text dubbifamuu akka danda'u godhi.

3️⃣ Color

Halluu baay'ee walitti makuu irra, halluuwwan wal siman muraasa fayyadami.

4️⃣ Typography

Font sirrii filachuun design professional taasisuu keessatti gahee guddaa qaba.

5️⃣ Spacing

Text fi objects gidduutti space gahaa dhiisi. Design kee akka hin caccabne godhi.

💻 Practical

PixelLab keessatti poster haaraa tokko uumi. Lesson 1 keessatti baratte fi principles Lesson 2 keessatti baratte walitti maki.
