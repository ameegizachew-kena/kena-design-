LESSON 1 — PIXELLAB

PixelLab Sirriitti Baradhu

Lesson kana keessatti PixelLab Google Play irraa buufatamu fayyadamuun graphic design bu'uuraa irraa kaasee hanga design export gochuutti tartiiba tartiibaan baranna.

📱 PixelLab Google Play Irraa Buufadhu ➡️ Link cuqaasi → Install → Open

1. 📱 PixelLab Maal?

PixelLab app Android irratti text fi graphic design hojjechuuf fayyadamuudha. Poster, thumbnail, flyer, social media design, logo-style design fi hojiiwwan text irratti hundaa'an hojjechuuf si gargaara.

➡️ Bakka: App erga bantee booda fuula hojii PixelLab fi toolbar isaa argita.

2. 📥 PixelLab Install Gochuu

1️⃣ Google Play bani.
2️⃣ Search keessatti PixelLab barreessi.
3️⃣ PixelLab kan Imaginstudio jedhu filadhu.
4️⃣ Install cuqaasi.
5️⃣ Erga install ta'ee booda Open cuqaasi.
➡️ PixelLab Google Play Bani
💡 Hubachiisa: Lesson kun PixelLab kan Google Play irratti argamu irratti hundaa'a.

3. 🖥️ PixelLab Interface

PixelLab yeroo bante, bakka hojii guddaa fi tools gara garaa argita.

➡️ Canvas: bakka design kee itti ijaartu.
➡️ Toolbar: bakka tools gara garaa itti argattu.
➡️ Object controls: text ykn image filattee booda options isaa ittiin jijjiirtu.
➡️ Layers/Object order: objects hedduu yeroo qabaattu tartiiba isaanii to'achuuf.
⚠️ Maqaan ykn mallattoon tokko tokko version Android/app irratti xiqqoo garaagaruu danda'a. Garuu hojii isaanii wal fakkaata.

4. ✏️ Text — Barreessuu

Text PixelLab keessatti tool isa ijoodha. Maqaa, title, slogan, caption fi barruu biroo ittiin barreessita.

➡️ Bakka itti argamu: Toolbar keessatti mallattoo T / Text barbaadi.
1️⃣ Text/T cuqaasi.
2️⃣ Barruu kee barreessi.
3️⃣ OK/✓ cuqaasi.
4️⃣ Text filadhu.
5️⃣ Size fi position isaa sirreessi.
🎯 Shaakala: “KENA DESIGN” barreessi.

5. 🔤 Font — Boca Qubee

Font jechuun bifa qubee barruu keetii jijjiiruudha.

➡️ Bakka itti argamu: Text filadhu → menu text → Font.
1️⃣ Text filadhu.
2️⃣ Font cuqaasi.
3️⃣ Font barbaadde filadhu.
4️⃣ ✓/Apply godhi.

Font tokko tokko title, logo, poster ykn thumbnail irratti caalaatti bareeda.

6. 🎨 Color — Halluu

Color fayyadamuun text ykn object kee halluu barbaaddeen goota.

➡️ Bakka itti argamu: Text ykn shape filadhu → Color.
1️⃣ Object filadhu.
2️⃣ Color filadhu.
3️⃣ Halluu filadhu.
4️⃣ ✓ cuqaasi.
🎯 Background dukkanaa irratti text adii ykn magariisaa yaali.

7. 🧊 3D Text

3D Text text kee akka depth qabu fakkeessa.

➡️ Bakka itti argamu: Text filadhu → 3D Text / 3D settings barbaadi.
1️⃣ Text filadhu.
2️⃣ 3D option banu.
3️⃣ Depth ykn angle sirreessi.
4️⃣ Preview ilaali.

8. ✨ Text Effects

Effects text kee caalaatti bareedaa fi ifa godhu.

➡️ Bakka itti argamu: Text filadhu → Effects / Style.
  • 🌑 Shadow — gaaddisa
  • 🔲 Stroke — daangaa text
  • 🎨 Background — text duuba halluu
  • ✨ Reflection — calaqqee
  • 🪨 Emboss — bifa ol-ka'aa fakkeessu

9. 🏷️ Stickers & Shapes

Stickers fi Shapes design kee decoration gochuuf gargaaru.

➡️ Bakka itti argamu: Toolbar/menu keessaa Shapes / Stickers.
Shape ykn sticker filadhu.
Canvas irratti kaa'i.
Size fi position jijjiiri.

10. 🖼️ Import Image

Gallery irraa suuraa gara PixelLab keessa galchuuf fayyada.

➡️ Bakka itti argamu: Toolbar → Image / Import → Gallery.
1️⃣ Image/Import filadhu.
2️⃣ Gallery bani.
3️⃣ Suuraa filadhu.
4️⃣ ✓ cuqaasi.
5️⃣ Size fi position sirreessi.

11. ✍️ Draw

Draw tool'n harka kee fayyadamuun line fi mallattoo kaasuuf si gargaara.

➡️ Bakka itti argamu: Toolbar keessaa Draw barbaadi.
Brush filadhu.
Thickness sirreessi.
Color filadhu.
Canvas irratti kaasi.

12. 🌄 Background

Background jechuun duubbee design keetii.

➡️ Bakka itti argamu: Menu keessatti Background barbaadi.
Color ykn Image filadhu.
Duubbee design kee waliin madaali.

13. ✂️ Background Removal

Suuraa keessaa background balleessuun subject qofa hambisuuf fayyada.

➡️ Bakka itti argamu: Image filadhu → editing/options keessaa background removal ykn erase-related option barbaadi.
💡 Version app irratti maqaan option xiqqoo garaagaruu danda'a.

14. 🔄 Perspective Editing

Perspective tool'n image ykn object kee angle addaatiin qindeessuuf fayyada.

➡️ Bakka itti argamu: Image/object filadhu → Perspective / Transform.
Corner ykn point qabsiisi.
Harkisi.
Angle barbaadde argadhu.
✓ Apply godhi.

15. 🌈 Image Effects

Image Effect suuraa kee fooyyeessuuf gargaaru.

➡️ Bakka itti argamu: Image filadhu → Effects / Adjustments.
  • Brightness
  • Contrast
  • Saturation
  • Blur
  • Color effects
Effect filadhu → intensity sirreessi → preview ilaali → Apply.

16. 🧱 Layers / Objects

Design keessatti object hedduu yeroo qabaattu layers isaan qindeessuuf si gargaara.

➡️ Bakka itti argamu: Toolbar/menu keessatti Layers / Objects control barbaadi.
  • ⬆️ Object ol siqsiisuu
  • ⬇️ Object gadi siqsiisuu
  • 👁️ Hide/Show
  • 📋 Duplicate
  • 🗑️ Delete
  • 🔄 Object order jijjiiruu

17. 💾 Save Project

Project save yoo goote yeroo biraa deebi'ee gulaaluu dandeessa.

➡️ Bakka itti argamu: Menu → Save Project.
1️⃣ Save Project filadhu.
2️⃣ Maqaa project kenni.
3️⃣ Save godhi.

18. 📤 Export / Save as Image

Design xumurte booda gara PNG ykn JPG tti baasuuf fayyada.

➡️ Bakka itti argamu: Menu → Export / Save as Image.
1️⃣ Export filadhu.
2️⃣ PNG ykn JPG filadhu.
3️⃣ Quality filadhu.
4️⃣ Save/Export cuqaasi.
