🎨 Graphic Design jechuun maal?

Graphic Design jechuun yaada, ergaa ykn odeeffannoo tokko karaa suuraa, halluu, barruu, shape fi qindaa'ina gara nama ilaaluuf salphaa fi bareedaatti jijjiiruu dha.

Graphic Designer tokko poster, logo, flyer, social media design, YouTube thumbnail, advertisement, banner fi hojiiwwan biroo uuma.

💡 Yaadadhu: Design gaariin bareedina qofa miti. Ergaa sirriitti dabarsuu fi nama ilaaluuf salphaa ta'uu qaba.

📱 PixelLab jechuun maal?

PixelLab application Android irratti graphic design fi text design hojjechuuf gargaaru dha.

PixelLab keessatti barruu, font, color, image, shape, shadow, stroke, background fi effects adda addaa fayyadamuun design garaagaraa uumuu dandeessa.

Fakkeenyaaf, PixelLab fayyadamuun:

  • Poster
  • Flyer
  • YouTube Thumbnail
  • Social Media Post
  • Advertisement
  • Quote Design
  • Text Logo
  • Banner

📱 PixelLab Interface

Interface jechuun fuula application keessatti wantoota ittiin hojii hojjetu argitu jechuudha.

PixelLab yeroo banu wantoota ijoo armaan gadii arguu dandeessa:

  1. Top Bar
  2. Canvas
  3. Text/Object
  4. Tools Menu
  5. Layers / Objects
  6. Background
  7. Export / Save

🛠️ Tools fi Features

Amma PixelLab keessatti tools fi features ijoo tokko tokkoon haa ilaallu.

1️⃣ Text Tool

Text Tool fayyadamuun barruu gara canvas irratti dabaluu dandeessa.

Fakkeenyaaf maqaa, mata-duree, ergaa, quote ykn advertisement barreessuu dandeessa.

2️⃣ Font

Font jechuun bifa barruu ti. Font adda addaa fayyadamuun design kee garaagaraa gochuu dandeessa.

Mata-duree irratti font cimaa fi dubbifamuu salphaa fayyadamuun barbaachisaa dha.

3️⃣ Text Size

Text Size fayyadamuun guddina barruu sirreessita.

Mata-dureen guddaa, barruun ibsaa immoo xiqqaa ta'uu danda'a.

4️⃣ Text Color

Text Color fayyadamuun halluu barruu jijjiiruu dandeessa.

Halluu background waliin wal faallaa ta'e filadhu, barruun akka ifatti dubbifamu godhi.

5️⃣ Text Style

Text Style keessatti barruu garaagarummaa qabu uumuuf style adda addaa fayyadamta.

  • Bold
  • Italic
  • Underline
  • Spacing
  • Alignment

6️⃣ Stroke

Stroke jechuun daangaa ykn sarara barruu naannoo isaa jiruudha.

Barruu background irratti akka ifatti mul'atuuf Stroke fayyadamuun ni danda'ama.

7️⃣ Shadow

Shadow jechuun gaaddisa barruu ykn object duuba jiruudha.

Shadow sirriitti fayyadamuun design kee keessatti depth fi separation uuma.

8️⃣ Alignment

Alignment jechuun wantoota design keessa jiran sirnaan qindeessuu dha.

  • Left
  • Center
  • Right

9️⃣ Position / Move

Object tokko bakka tokko irraa gara bakka biraatti sochoosuuf Position ykn Move fayyadamta.

🔟 Rotate

Rotate fayyadamuun text, image ykn shape gara bita ykn mirga naannessuu dandeessa.

1️⃣1️⃣ Opacity

Opacity jechuun ifa ykn mul'ata object tokkoo sirreessuu dha.

Opacity 100% jechuun guutumaan guutuutti mul'ata. Yoo gadi buuste object sun translucent ta'a.

1️⃣2️⃣ Shape

Shape fayyadamuun rectangle, circle fi shapes biroo design kee keessatti galchuu dandeessa.

Shape:

  • Decoration
  • Background element
  • Frame
  • Text background
  • Button design

1️⃣3️⃣ Image

Image tool fayyadamuun suuraa gallery keessaa gara PixelLab galchuu dandeessa.

Suuraa erga galchitee booda:

  • Resize
  • Move
  • Rotate
  • Crop
  • Opacity
  • Position

1️⃣4️⃣ Background

Background jechuun duuba design kee jiruudha.

Background:

  • Color
  • Gradient
  • Image
  • Texture

1️⃣5️⃣ Layers / Objects

Layers ykn Objects jechuun wantoota design kee keessa jiran tokko tokkoon to'achuudha.

Fakkeenyaaf Text, Image fi Shape addaan addaan filachuu, sochoosuu ykn haquu dandeessa.

1️⃣6️⃣ Effects

Effects fayyadamuun design kee irratti miidhagina dabalataa uumuu dandeessa.

  • Shadow
  • Stroke
  • Emboss
  • Reflection
  • Gradient

1️⃣7️⃣ Draw

Draw tool fayyadamuun harkaan sarara ykn mallattoo gara canvas irratti kaasuu dandeessa.

1️⃣8️⃣ Save Project

Hojii kee gara fuulduraatti itti deebitee fooyyeessuuf project isaa save gochuun barbaachisaa dha.

1️⃣9️⃣ Export

Design kee xumurte booda image godhuuf Export fayyadamta.

Fakkeenyaaf:

  • JPG
  • PNG
