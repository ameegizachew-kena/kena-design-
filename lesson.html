📚 Note Bal'aa — PixelLab Tools fi Features

Video erga ilaaltanii booda, tool tokkoon tokkoon isaa maal akka ta'e, maaliif akka fayyadu, akkamitti akka fayyadamu fi bakka inni PixelLab keessatti argamu hubadhu. Screenshot irratti cuqaasuun guddisanii ilaalu dandeessa.

💡 Hubannoo Guddaa

PixelLab'n mobile irratti graphic design hojjechuuf app salphaa fi humna qabuudha. Text, 3D Text, Text Effects, Fonts, Colors, Stickers, Images, Draw, Background, Save Project, Background Removal, Perspective fi Image Effects fayyadamuun poster, logo, quote, thumbnail fi hojiiwwan graphics biroo hojjechuu dandeessa. 1

🛠️ Tool Tokkoon Tokkoon

Screenshot hunda tuqi → guddisii ilaali. Ibsa, faayidaa, akkamitti itti fayyadamtu fi bakka inni jiru ilaali.

1

Text

Maal?
Text jechuun barreeffama project keessa galchuudha.

Maaliif?
Maqaa, title, quote, slogan fi odeeffannoo poster irratti barreessuuf.

Akkamitti?
+ tuqi → Text filadhu → barreeffama kee barreessi.

📍 Bakka: + → Text

2

Fonts

Maal?
Font jechuun bifa qubee barreeffamaa ti.

Maaliif?
Design kee professional fi nama hawwatu gochuuf.

Akkamitti?
Text filadhu → Font → font barbaadde filadhu.

📍 Bakka: Text → Font

3

Colors

Maal?
Halluu Text ykn object jijjiira.

Maaliif?
Halluu wal simsiisuun design kee bareechuuf.

Akkamitti?
Text filadhu → Color → halluu filadhu.

📍 Bakka: Text → Color

4

Shadow

Maal?
Text jala ykn cina isaa gaaddisa uuma.

Maaliif?
Text background irraa adda baasuuf.

Akkamitti?
Text → Shadow → color, blur fi opacity sirreessi.

📍 Bakka: Text → Shadow

5

3D Text

Maal?
Text akka 3D fakkaatutti jijjiira.

Maaliif?
Poster fi title keessatti effect jabaa uumuuf.

Akkamitti?
Text filadhu → 3D Text → depth fi style sirreessi.

📍 Bakka: Text → 3D Text

6

Text Effects

Maal?
Shadow, Stroke, Reflection, Emboss fi effects gara Textitti dabala.

Maaliif?
Text akka ifa ta'ee mul'atuuf.

Akkamitti?
Text → Effects → effect barbaadde bana.

📍 Bakka: Text → Effects

7

Stickers

Maal?
Emoji, sticker fi shapes itti dabala.

Maaliif?
Poster decoration fi social media design'f.

Akkamitti?
+ → Stickers → sticker filadhu → size fi rotation sirreessi.

📍 Bakka: + → Stickers

8

Import Images

Maal?
Gallery keessaa suuraa project keessa galcha.

Maaliif?
Suuraa namaa, logo, product ykn background itti fayyadamuuf.

Akkamitti?
+ → Image → Gallery keessaa suuraa filadhu.

📍 Bakka: + → Image

9

Draw

Maal?
Qalam fayyadamuun harkaan kaasuuf.

Maaliif?
Mallattoo, sarara ykn fakkii addaa uumuuf.

Akkamitti?
+ → Draw → pen size fi color filadhu → kaasi.

📍 Bakka: + → Draw

10

Background

Maal?
Duuba projectii halluu ykn image godha.

Maaliif?
Design kee irratti mood fi color scheme uumuuf.

Akkamitti?
Background → Color, Gradient ykn Image filadhu.

📍 Bakka: Background

11

Remove Background

Maal?
Background suuraa keessaa haqa.

Maaliif?
Nama ykn object qofa baasanii poster irratti kaa'uuf.

Akkamitti?
Image filadhu → Remove Background → background haqii.

📍 Bakka: Image → Remove Background
