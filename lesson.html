📖 NOTE BAL'AA – PixelLab Tools fi Features

Video irratti argite sana waliin wal qabsiisuun, tools tokkoon tokkoon isaanii maal akka ta'an, maaliif akka fayyadan fi akkamitti akka itti fayyadaman as keessatti baradhu. Screenshot tokkoon tokkoon tool bakka inni PixelLab keessatti argamu hubachuuf si gargaara.

🛠️ PixelLab Tools 15

Tool tokko filadhu; maqaa isaa, hojii isaa fi bakka itti argamu ilaali.

1

Text

Barreeffama poster, logo, quote fi thumbnail keessatti galchuuf fayyada.

📍 Bakka: + → Text

2

Fonts

Boca qubee fi style isaa jijjiiruuf fayyada.

📍 Bakka: Text → Font

3

Color

Halluu text ykn object jijjiiruuf fayyada.

📍 Bakka: Text → Color

4

Shadow

Text irratti gaaddisa uumee akka mul'atu fi professional fakkaatu godha.

📍 Bakka: Text → Shadow

5

3D Text

Barreeffama gara 3D fakkaatutti jijjiira.

📍 Bakka: Text → 3D Text

6

Text Effects

Stroke, Background, Reflection, Emboss fi effects biroo itti dabaluuf fayyada.

📍 Bakka: Text → Effects

7

Stickers

Emoji, sticker fi mallattoolee gara poster keetti galchuuf fayyada.

📍 Bakka: + → Stickers

8

Image Import

Suuraa phone keessaa gara projectitti galchuuf fayyada.

📍 Bakka: + → Image

9

Draw

Harkaan sarara, mallattoo fi fakkii xiqqaa kaasuu dandeessa.

📍 Bakka: + → Draw

10

Background

Background color, gradient ykn image kaa'uuf fayyada.

📍 Bakka: Background

11

Remove Background

Background suuraa keessaa haquuf fayyada.

📍 Bakka: Image → Remove Background

12

Perspective

Object ykn image angle isaa jijjiiruuf fayyada.

📍 Bakka: Object → Perspective

13

Layers

Object tokko tokko addaan baasuu, fuuldura ykn duuba kaa'uuf fayyada.

📍 Bakka: Layers menu

14

Save Project

Project kee akka booda deebitee itti hojjettuuf save godhuuf fayyada.

📍 Bakka: Save → Save as Project

15

Export

Design kee JPG ykn PNG godhee phone keessatti save gochuuf fayyada.

📍 Bakka: Save / Export
