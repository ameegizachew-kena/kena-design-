03 • FILE TYPES

📁 TTF fi OTF maal?

.TTF

TrueType Font. Mobile design keessatti baay'ee beekamaa fi salphaatti import ta'uudha.

.OTF

OpenType Font. Innis font file beekamaa dha; PixelLab versions heddu keessatti fayyadamuun ni danda'ama.

ZIP/RAR: Yoo font .zip ykn .rar ta'e, kallattiin PixelLab keessa hin filatin. Dura Extract godhi; keessaa TTF/OTF baasi.

04 • STEP BY STEP

📲 Font haaraa PixelLab keessa galchuu

  1. Font barbaadi: Font ati barbaaddu buufadhu. File isaa TTF ykn OTF ta'uu mirkaneessi.
  2. Download: Browser kee irraa font file buufadhu. Yeroo baay'ee Downloads keessa seena.
  3. ZIP yoo ta'e: File ZIP baniitii Extract godhi.
  4. TTF/OTF barbaadi: Folder extract godhame keessa seeni; file font dhugaa filadhu.
  5. PixelLab bani: Project haaraa bani ykn project duraan jiru bani.
  6. Text filadhu: Text layer tokko tuqi; sana booda menu A irraa text tools bani.
  7. Font bani: Toolbar keessa gara Font deemi.
  8. My Fonts filadhu: Tab/menu MY FONTS bani.
  9. + tuqi: Mallattoo folder/plus ykn add font jiru tuqi.
  10. Folder barbaadi: Downloads, Fonts ykn folder ati font itti kaa'etti deemi.
  11. Font filadhu: TTF/OTF file filadhu. Version tokko tokko keessatti Add Selected/Add Directory/OK jedhu mul'ata.
  12. Font itti fayyadami: Font haaraa My Fonts keessatti mul'ata. Isa tuqi; text kee irratti hojiirra oola.
  13. Test godhi: Qubee guddaa, qubee xiqqaa, lakkoofsa fi jechoota Afaan Oromoo barreessuun ilaali.
🧭 Bakka ijoo yaadadhu: Text → Font → MY FONTS → +/Folder → Download/Fonts → Font file → Add/OK → Font filadhu.
