PixelLab Tools fi Features

Lesson kana keessatti PixelLab maal akka ta'e, tool tokkoon tokkoon isaa eessa akka argamu, maalif akka fayyadu fi akkamitti akka itti fayyadamtu tartiiba salphaan baratta.

🎯 Kaayyoon Lesson 1: dhuma irratti poster, thumbnail ykn design salphaa tokko ofii keetiin PixelLab keessatti uumuu.

1. Seensa 2. Install 3. Interface 4. Text 5. Effects 6. Images 7. Layers 8. Background 9. Save 10. Export Practice

🎨 1. PixelLab jechuun maal?

PixelLab app mobile irratti graphic design, text design, poster, thumbnail, logo, social-media design fi hojiiwwan biroo hojjechuuf gargaarudha.

Appichi text, 3D text, fonts, colors, stickers, images, drawing, backgrounds, layers/project saving, background removal, perspective editing, image effects fi export qaba. 3

💡 Yaadadhu: PixelLab button qofa miti. Toolwwan isaa walitti fiduun design tokko ijaartu.

🖥️ 3. Interface — Fuula jalqabaa

PixelLab bannee yeroo jalqabaaf ilaallu, canvas, toolbar fi object text argina. Version appii irratti hundaa'uun mallattooleen bakka xiqqoo garaagarummaa qabaachuu danda'u.

Fakkeenya PixelLab interface fi text editing.

➕

Plus (+) — Wantoota haaraa dabali

📍 Toolbar gubbaa → +

Plus yeroo cuqaastu, Text, Stickers, Shapes, Image fi wantoota biroo itti dabaluuf menu siif bana.

Maaliif?
Design kee keessatti elementii haaraa uumuuf.

Akkamitti?
+ → Text filadhu → text kee barreessi.

✏️

Edit / Pencil — Object jijjiiri

📍 Object filadhu → Edit/Pencil

Text ykn object filattee content, size, color, font fi style isaa jijjiiruu dandeessa.

▱

Layers — Objectwwan tartiibaan qindeessi

📍 Toolbar → Layers icon

Object tokko kan biraa duuba ykn fuuldura kaa'uu, dhoksuu, lock gochuu fi delete gochuuf layers fayyadami.

🔤 4. Text Tool

T

Text — Barreeffama

📍 + → Text

Text tool’n maqaa, mata-duree, slogan, caption fi odeeffannoo design keessatti barreessuuf fayyada.

Maaliif?
Ergaa design kee namaaf dabarsuuf.

Akkamitti?

  1. + cuqaasi.
  2. Text filadhu.
  3. “New Text” irratti cuqaasi.
  4. Barreeffama kee galchi.
  5. ✓/OK cuqaasi.
  6. Text sana bakka barbaadde kaa'i.
Fakkeenya:
“KENA DESIGN” mata-duree poster ta'uu danda'a.
3D

3D Text

📍 Text/Object → 3D ykn Text Effects

Text kee gara fakkii sadii-dimensionaatti fakkeessuuf 3D Text fayyadami.

Maaliif?
Mata-duree poster ykn thumbnail akka cimaa fi hawwataa fakkaatu gochuuf.

Akkamitti?
Text filadhu → 3D option barbaadi → depth/lighting/shadow sirreessi.

🔠 5. Font Tool

F

Font — Boca qubee

📍 Text filadhu → Font

Font jechuun bifa qubee barreeffamaati. PixelLab keessatti fontwwan hedduu keessaa filachuu ykn font mataa keetii fayyadamuu dandeessa. 5

Maaliif?
Design kee professional fi dubbifamuu salphaa akka ta'uuf.

📌 Seera jalqabaa:
Poster tokko keessatti font baay'ee walitti hin makiin. Mata-duree tokko fi body text tokkoon jalqabi.

🎨 6. Color Tool

●

Text Color

📍 Text filadhu → Color

Text irratti color salphaa, gradient fi texture fakkaatan fayyadamuuf ni dandeessa. 6

Maaliif?
Text background irraa adda akka ba'uuf.

Akkamitti?
Text filadhu → Color → color filadhu → ✓.

✨ 7. Text Effects

Effects text kee ifa, gadi-fageenya fi adda-bahinsa akka qabaatu godhu.

🌑 Shadow

Text duuba shadow kaa'a. Text background irraa adda baasuuf baay'ee fayyada.

📍 Text → Shadow

⭕ Stroke

Text marsaan isaa outline argata. Background halluu hedduu qabu irratti dubbifamuu fooyyeessa.

📍 Text → Stroke

💡 Background / BG

Text duuba box ykn background kaa'a. Caption fi announcement irratti gaarii dha.

🪞 Reflection / Emboss / Mask

Reflection text akka calaqqisu godha. Emboss text akka ol-ka'e fakkeessa. Mask ammoo text effect addaa uumuuf fayyada.

⚠️ Hubadhu: Effect baay'ee yeroo tokko irratti hin fe'in. Design qulqulluu ta'uu qaba.

😀 8. Stickers & Shapes

⭐

Stickers

📍 + → Stickers

Emoji, sticker fi shapes design irratti dabaluuf fayyadami.

Maaliif?
Design kee message isaa cimsuuf.

Akkamitti?
+ → Stickers → sticker filadhu → size fi position sirreessi.

🖼️ 9. Image Import

🖼️

Import Image — Suuraa galchi

📍 + → Image / Gallery

Gallery mobile kee keessaa suuraa gara project PixelLab keessa galchuuf fayyada. 7

Fakkeenyaaf:

  • Suuraa namaa
  • Logo
  • Product photo
  • Sticker mataa keetii
  • Background image

Suuraa erga galchitee booda size, position, rotation fi effects isaa sirreessuu dandeessa.

✏️ 10. Draw Tool

✏️

Draw — Harkaan sarara hojjedhu

📍 + → Draw

Pen size fi color filattee canvas irratti harkaan drawing gochuu dandeessa. 8

Maaliif?
Arrow, underline, signature ykn mallattoo mataa keetii uumuuf.

Drawing erga hojjettee booda akka objectitti resize, rotate fi shadow gochuu dandeessa.

🌄 11. Background Tool

🌈

Change Background

📍 Background option

Background gara color, gradient ykn image tti jijjiiruu dandeessa. 9

Fakkeenya:

  • Poster → dark background
  • Thumbnail → colorful gradient
  • Business post → brand color

✂️ 12. Background Removal

✂️

Remove Background

📍 Image filadhu → Remove Background

Background suuraa keessaa haquun object qofa transparent gochuuf fayyada. Fakkeenyaaf nama tokko background irraa adda baasuu dandeessa. 10

Fakkeenya:
Suuraa namaa → Remove Background → nama qofa → background haaraa irratti kaa'i.

📐 13. Perspective Editing

📐

Perspective / Warp

📍 Image/Text → Perspective/Warp

Object ykn text tokko akka kallattii addaa keessa jiru fakkeessuuf fayyada. 11

Fakkeenya:

  • Logo gara box irratti kaa'u
  • Text gara road sign irratti kaa'u
  • Screen/monitor irratti design kaa'u

🌟 14. Image Effects

✨

Effects

📍 Image filadhu → Effects

Suuraa kee look isaa fooyyeessuuf effects akka vignette, hue, saturation fi effects biroo fayyadamuu dandeessa. 12

Yaada: Effect xiqqoo fayyadami; suuraa akka artificial hin fakkaanne eegi.

📚 15. Layers

▱

Layers — Tartiiba Object

📍 Toolbar → Layers

Layers jechuun objectwwan design kee keessa jiran tartiiba isaanii to'achuudha.

Fakkeenyaaf:

  1. Background
  2. Image
  3. Shape
  4. Main Text
  5. Small Text

Object tokko fuuldura ykn duuba kaa'uu, hide, lock fi delete gochuu keessatti layers baay'ee barbaachisaa dha.

Fakkeenya layers panel fi object controls.

💾 16. Save as Project

💾

Project Save

📍 Toolbar → Save / Project

Hojii kee project godhanii save gochuun, yeroo biraa deebi'anii itti fufuuf si gargaara. 13

Maaliif?
Design kee yeroo hunda image qofa osoo hin taane project editable ta'ee akka siif hafuuf.

Fakkeenyaaf: har'a poster jalqabde → project save godhi → boru deebi'ii text fi image jijjiiri.

📤 17. Export Image

📤

Export — Design kee baasi

📍 Toolbar → Save/Export

Design xumurte booda image akka filetti save ykn share gochuuf Export fayyadami. Resolution fi format filachuu dandeessa. 14

Fakkeenya:

  • WhatsApp irratti erguuf
  • Facebook irratti maxxansuuf
  • YouTube Thumbnail gochuuf
  • Poster print gochuuf
