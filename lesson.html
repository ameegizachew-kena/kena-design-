📚 Lesson 2: Font Haaraa PixelLab Keessatti Galchuu

Font jechuun bifa qubee ittiin barruun mul'atuudha. Graphic Design keessatti font sirrii filachuun design kee bareedaa fi professional akka fakkaatu gargaara.

💡 Yaadadhu: Font baay'ee qabaachuun qofa gahaa miti. Font bakka sirrii fi design wajjin wal simu fayyadamuun barbaachisaadha.

🔤 Gosoota Font

1️⃣ Serif

Qubee xixiqqoo miila ykn mallattoo xumuraa qabu. Kitaaba, barruu dheeraa fi hojii professional keessatti fayyada.

2️⃣ Sans Serif

Qubee qulqulluu fi salphaa. Logo, social media fi web design keessatti baay'ee fayyada.

3️⃣ Script

Qubee harkaan barreeffame fakkaatu. Invitation fi design artistic keessatti fayyada.

4️⃣ Display

Mata-duree guddaa fi poster irratti nama hawwatuuf fayyada.

📁 TTF fi OTF Maali?

Font download gootu yeroo baay'ee extension:

  • .TTF — TrueType Font
  • .OTF — OpenType Font
📌 PixelLab keessatti font haaraa fayyadamuuf font file buufattee booda import gochuu dandeessa.

📱 Font Haaraa PixelLab Keessatti Galchuuf Tarkaanfii

  1. Font barbaadde internet irraa download godhi.
  2. File manager bani.
  3. Font file `.ttf` ykn `.otf` barbaadi.
  4. PixelLab bani.
  5. Text irratti cuqaasi.
  6. Font option bani.
  7. My Fonts ykn Add Font filadhu.
  8. Font file kee filadhu.
  9. Font sana import godhi.
  10. Barreeffama kee irratti font haaraa hojiirra oolchi.
