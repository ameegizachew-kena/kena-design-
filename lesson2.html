📘 Lesson 2: PixelLab keessatti Font Haaraa Dabaluu

Barnoota kana keessatti PixelLab irratti font haaraa akkamitti dabaluu akka dandeessu tartiiba sirriin baratta.

Font adda addaa fayyadamuun poster, logo, YouTube thumbnail, social media design fi hojii graphics kee akka bareedu si gargaara.

💡 Yaadannoo: Font gaarii filachuun design kee qulqullina fi professional akka fakkaatu godha.

🎥 Video Lesson

Video kana dura ilaali. Sana booda tarkaanfiiwwan barreeffaman armaan gadi hordofi.

1️⃣ Font jechuun maal?

Font jechuun bifa barreeffamaa ykn style qubee ati design kee keessatti fayyadamtuudha.

Fakkeenyaaf:

  • Arial
  • Roboto
  • Montserrat
  • Poppins
  • Open Sans
  • Fonts artistic adda addaa
🔤

FONT

Font jijjiiruun bifa barreeffamaa design kee jijjiira.

2️⃣ Akaakuu Font

📄 TTF

TTF jechuun TrueType Font dha. Android irratti baay'ee beekamaa fi fayyadamuuf salphaa dha.

📄 OTF

OTF jechuun OpenType Font dha. Font qulqullina gaarii qabu fi hojii design adda addaaf mijataa dha.

💡 Gorsa: Font haaraa buufattu yeroo baayyee TTF ykn OTF ta'uu isaa ilaali.

3️⃣ Tarkaanfii 1 — Font barbaadi

Step 1: Browser kee bani.
Step 2: Font barbaaddu barbaadi.
Step 3: Font amanamaa irraa download godhi.
🌐

FONT DOWNLOAD

Font kee buufadhu; yeroo baay'ee faayiliin ZIP ykn TTF/OTF ta'a.

4️⃣ Tarkaanfii 2 — Download folder bani

Step 1: File Manager ykn Files app bani.
Step 2: Gara Downloads seeni.
Step 3: Font ati buufatte barbaadi.
📁

DOWNLOADS

Font kee Downloads keessatti argachuu dandeessa.

5️⃣ Tarkaanfii 3 — ZIP yoo ta'e baasuu

Font kee yoo .zip ta'e, dura Extract/Unzip godhi.

Step 1: ZIP file tuqi.
Step 2: Extract ykn Unzip filadhu.
Step 3: Keessa isaa TTF ykn OTF barbaadi.
🗜️

EXTRACT

ZIP → TTF / OTF

6️⃣ Tarkaanfii 4 — PixelLab bani

Step 1: PixelLab app bani.
Step 2: Project haaraa bani ykn project duraanii bani.
🎨

PIXELLAB

8️⃣ Tarkaanfii 6 — My Fonts / Custom Fonts

PixelLab version tokko tokko keessatti maqaan menu xiqqoo garaagarummaa qabaachuu danda'a.

Step 1: Font menu keessatti My Fonts ykn Custom Font barbaadi.
Step 2: Add (+) ykn import option tuqi.
➕

ADD FONT

Step 1: File Manager bana.

FONT.TTF

🎯 Font Maaliif Barbaachisa?

  • Design kee professional taasisa.
  • Brand identity ijaaruuf gargaara.
  • Poster kee nama hawwata.
  • YouTube thumbnail kee bareecha.
  • Social media design kee fooyyeessa.
  • Logo design keessatti filannoo bal'aa siif kenna.

⚠️ Dogoggora Yeroo Baay'ee Mul'atu

1. Font hin mul'atu

Font sirriitti extract ta'uu fi TTF/OTF ta'uu isaa ilaali.

2. ZIP file qofa filachuu

ZIP osoo hin taane keessaa TTF ykn OTF filadhu.

3. Font baay'ee fayyadamu

Design tokko keessatti font baay'ee walitti makuun qulqullina design hir'isuu danda'a.

4. Font dubbifamuu hin dandeenye

Font artistic baay'ee ta'e yeroo tokko tokko readability hir'isa.

🧪 Shaakala

Amma ofii keetiin hojii kana hojjedhu:

  1. Font tokko buufadhu.
  2. Yoo ZIP ta'e extract godhi.
  3. TTF ykn OTF file argadhu.
  4. PixelLab bani.
  5. Text tokko uumi.
  6. My Fonts/Custom Font bani.
  7. Font kee import godhi.
  8. Font haaraa text kee irratti hojii irra oolchi.
🎯 Kaayyoo: Ati ofii keetiin font haaraa PixelLab keessatti galchuu dandeessuu qabda.
