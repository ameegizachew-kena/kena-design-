📝 NOTE BAL'AA — FONT HAARAA PIXELLAB KEESSATTI GALCHUU

Font jechuun maal?

Font jechuun akkaataa barruun itti bocamu fi itti mul'atuudha. Fakkeenyaaf font tokko handwriting fakkaachuu danda'a, kan biraa bold ta'uu danda'a, kan biraa ammoo modern ykn professional fakkaachuu danda'a.

Design keessatti font filannoon baay'ee barbaachisaa dha. Font sirrii yoo filatte, poster, flyer, thumbnail, logo fi social media design kee bareedaa fi professional fakkaata.

🎯 Font maaliif barbaachisa?

  • Design kee bareechisa.
  • Ergaa design keessa jiru ifa godha.
  • Brand kee adda baasa.
  • Poster fi Flyer irratti style kenna.
  • Thumbnail nama hawwatu uumuuf gargaara.
  • Barruun akka salphaatti dubbifamu taasisa.
⚠️ Hubachiisa:
Font baay'ee walitti makuun design kee burjaajessuu danda'a. Yeroo baay'ee font 2 ykn 3 caalaa fayyadamuun hin barbaachisu.

TTF fi OTF jechuun maal?

TTF — TrueType Font: format font beekamaa kan app fi computer hedduu irratti hojjetudha.

OTF — OpenType Font: format font ammayyaa kan typography fi amaloota font dabalataa qabaachuu danda'uudha.

PixelLab keessatti yeroo baay'ee font .ttf ykn .otf fayyadamna.

📌 Tartiiba guddaa yaadadhu:
Download → Extract → TTF/OTF → PixelLab → Font → My Fonts → Add → Select → Apply → Design

👀 VISUAL GUIDE — TARKAANFII 12

👆
PIXELLAB
1️⃣ PixelLab Bani

🎯 Kaayyoo: App PixelLab keessatti hojii jalqabuuf.

📖 Ibsa bal'aa: Jalqaba PixelLab bilbila kee irratti bani. App erga banamee booda canvas hojii ittiin hojjetu argita. Canvas jechuun bakka design kee itti ijaartuudha.

👆 Maal tuquu qabda? PixelLab icon tuqiitii app bani.

❓ Maaliif? Font haaraa galchuuf jalqaba app keessa seenuu qabda.

📍 Bakka: PixelLab App

⚠️ Yoo app hin banamne: Internet yeroo baay'ee hin barbaachisu; garuu app sirriitti install ta'uu isaa fi bilbila kee irratti storage jiraachuu ilaali.

✅ Bu'aa: PixelLab canvas fuuldura kee irratti banamuu qaba.

🔍 Suuraa tuqi — guddisii ilaali.

👆
TEXT
2️⃣ Text Dabali

🎯 Kaayyoo: Barruu irratti font filannoo gochuuf Text layer qabaachuu.

📖 Ibsa bal'aa: PixelLab keessatti barruu tokko qabaachuun barbaachisaa dha. Text layer irratti font haaraa yaaluu dandeessa. Maqaa kee ykn jecha gabaabaa tokko barreessuun barnoota kanaaf gaarii dha.

👆 Maal tuquu qabda? Mallattoo A ykn Text jedhu barbaadiitii tuqi.

❓ Maaliif? Font haaraa erga galchitee booda barruu irratti hojii irra oolchuuf text layer barbaachisa.

📍 Bakka: PixelLab → Text

⚠️ Yoo Text hin mul'anne: Menu ykn toolbar gara jalaa fi gara olii ilaali. Version PixelLab garaagaraa ta'uu danda'a.

✅ Bu'aa: Canvas irratti barruun tokko mul'achuu qaba.

🔍 Suuraa tuqi — guddisii ilaali.

👆
SETTINGS
3️⃣ Text Settings Seeni

🎯 Kaayyoo: Bakka font itti argamu bira ga'uuf.

📖 Ibsa bal'aa: Text layer filattee yeroo tuqxu settings adda addaa argatta. Isaan keessaa Font jedhu barbaadi. Font menu keessatti fontwwan PixelLab duraan qabuu fi My Fonts arguu dandeessa.

👆 Maal tuquu qabda? Text filadhu → Text settings → Font.

❓ Maaliif? Font haaraa galchuuf gara Font menu seenuu qabda.

📍 Bakka: Text Controls → Font

⚠️ Hubachiisa: Menu maqaan isaa version app irratti xiqqoo garaagaruu danda'a.

✅ Bu'aa: Font menu siif banamuu qaba.

🔍 Suuraa tuqi — guddisii ilaali.

👆
FONT
4️⃣ Font Menu Filadhu

🎯 Kaayyoo: My Fonts bakka jedhu argachuu.

📖 Ibsa bal'aa: Font menu keessatti PixelLab fontwwan duraan qabdu agarsiisa. As keessatti bakka My Fonts, My Fonts ykn Custom Fonts fakkaatu barbaadi. Kun bakka font mataa keetii itti galchituudha.

👆 Maal tuquu qabda? Font menu keessatti My Fonts ykn Custom Fonts tuqi.

❓ Maaliif? Font haaraa bilbila irraa galchuuf bakka addaa kana fayyadamna.

📍 Bakka: Font Menu → My Fonts

⚠️ Yoo hin argamne: Font menu gadi fi oli sochoosi; version PixelLab tokko tokko maqaa menu garaagaraa qabaachuu danda'a.

✅ Bu'aa: My Fonts page ykn font import page siif banamuu qaba.

🔍 Suuraa tuqi — guddisii ilaali.

👆
MY FONTS
5️⃣ My Fonts Seeni

🎯 Kaayyoo: Font dhuunfaa galchuuf bakka sirrii argachuu.

📖 Ibsa bal'aa: My Fonts jechuun bakka PixelLab keessatti font ati mataa keetiin galchite itti kuufamuudha. As keessatti font duraan galfame yoo jiraate tarree isaa argita. Yoo font haaraa galchuu barbaadde, mallattoo Add ykn + barbaadi.

👆 Maal tuquu qabda? My Fonts keessatti +, Add ykn button font dabaluuf jiru barbaadi.

❓ Maaliif? PixelLabiin font haaraa akka barbaaduuf import process jalqabuuf.

📍 Bakka: My Fonts → Add / +

⚠️ Hubachiisa: Button Add bakka adda addaatti argamuu danda'a. Suuraa irratti mallattoo diimaa ilaali.

✅ Bu'aa: File Manager ykn font selection page banamuu qaba.

🔍 Suuraa tuqi — guddisii ilaali.

👆
ADD FONT
6️⃣ Add Font Filadhu

🎯 Kaayyoo: Font file gara PixelLabitti dabaluuf.

📖 Ibsa bal'aa: Amma File Manager ykn font picker siif banama. Bilbila kee keessatti font itti buufatte barbaadi. Yeroo baay'ee font Download folder keessa jira.

👆 Maal tuquu qabda? Download folder ykn bakka font itti kuufame seeni.

❓ Maaliif? PixelLabiin font file sirrii akka argatuuf.

📍 Bakka: File Manager → Download / Fonts

⚠️ Yoo font hin argamne: Download folder, Documents, Fonts fi ZIP extract gootee folder ilaali.

✅ Bu'aa: Font file kee tarree keessa mul'achuu qaba.

🔍 Suuraa tuqi — guddisii ilaali.

👆
FONT FILE
7️⃣ Font File Barbaadi

🎯 Kaayyoo: File font sirrii filachuu.

📖 Ibsa bal'aa: Tarree file keessaa maqaa font kee barbaadi. Font file yeroo baay'ee dhuma irratti .ttf ykn .otf qaba. Fakkeenyaaf: MyFont.ttf ykn MyFont.otf.

👆 Maal tuquu qabda? File font kee tuqi.

❓ Maaliif? File sirrii filachuun import akka milkaa'uuf barbaachisaa dha.

📍 Bakka: File Picker → .TTF / .OTF

⚠️ Hin filatin: ZIP, JPG, PNG ykn file design. Font file qofa filadhu.

✅ Bu'aa: PixelLab fonticha fudhachuuf qophaa'a.

🔍 Suuraa tuqi — guddisii ilaali.

👆
IMPORT
8️⃣ Import / Add Godhi

🎯 Kaayyoo: Font file filatame PixelLab keessatti galchuu.

📖 Ibsa bal'aa: Font file erga filattee booda PixelLab version kee irratti button Add, Select, Open ykn OK fakkaatu argachuu dandeessa. Maqaan button garaagaruu danda'a, garuu hojii isaa tokko: fonticha gara PixelLabitti galchuu.

👆 Maal tuquu qabda? Add / Select / Open / OK keessaa kan mul'atu tuqi.

❓ Maaliif? Font file akka PixelLab keessatti galmaa'uuf.

📍 Bakka: Font Import Dialog

⚠️ Yoo hin milkoofne: Font file sirrii ta'uu isaa, extension isaa fi extract gochuu kee mirkaneessi.

✅ Bu'aa: Fontiin My Fonts keessatti mul'achuu qaba.

🔍 Suuraa tuqi — guddisii ilaali.

👆
INSTALL
9️⃣ Font Install / Galmee

🎯 Kaayyoo: Font import xumuruu fi PixelLab keessatti galmeessuu.

📖 Ibsa bal'aa: Version PixelLab tokko tokko keessatti Add Directory, Add Selected, OK ykn button maqaa biraa arguu dandeessa. Kaayyoon isaa fonticha akka My Fonts keessatti galmaa'u gochuu dha.

👆 Maal tuquu qabda? Button Add / OK / Select kan mul'atu tuqi.

❓ Maaliif? Fonticha gara tarree My Fontsitti dabaluuf.

📍 Bakka: Import Dialog → Add / OK

⚠️ Hubachiisa: Maqaan button version app irratti garaagaruu danda'a.

✅ Bu'aa: Fontiin haaraan My Fonts keessatti mul'achuu qaba.

🔍 Suuraa tuqi — guddisii ilaali.

👆
SELECT
🔟 Font Haaraa Filadhu

🎯 Kaayyoo: Font galfame hojii irra oolchuu.

📖 Ibsa bal'aa: My Fonts keessatti maqaa font haaraa barbaadi. Fonticha tuqi. Yeroo tuqxu barruun kee fonticha fayyadamuun jijjiiramuu qaba.

👆 Maal tuquu qabda? Maqaa font haaraa tarree My Fonts keessaa tuqi.

❓ Maaliif? Import gochuun qofti gahaa miti. Fonticha barruu irratti apply gochuu qabda.

📍 Bakka: My Fonts → Font List

⚠️ Yoo hin mul'anne: PixelLab cufii irra deebiin bani ykn fonticha import irra deebi'i.

✅ Bu'aa: Barruun kee font haaraan mul'achuu qaba.

🔍 Suuraa tuqi — guddisii ilaali.

👆
APPLY
1️⃣1️⃣ Barruu Irratti Apply Godhi

🎯 Kaayyoo: Font haaraa design irratti sirriitti fayyadamuu.

📖 Ibsa bal'aa: Font tokko design irratti bareedaa fakkaachuu qofa osoo hin taane dubbifamuu qaba. Maqaa kee ykn sentence gabaabaa itti barreessi. Size, color, spacing fi effects isaa sirreessi.

👆 Maal tuquu qabda? Text filadhu → Font → font haaraa filadhu → Apply.

❓ Maaliif? Font tokko title irratti gaarii ta'uu danda'a, subtitle ykn body text irratti garuu dubbifamuu dhiisuu danda'a.

📍 Bakka: Canvas → Text Layer → Font Controls

⚠️ Hubadhu: Font decorative baay'ee ta'e barruu dheeraa irratti hin fayyadamin.

✅ Bu'aa: Barruun kee font haaraan ifatti mul'achuu qaba.

🔍 Suuraa tuqi — guddisii ilaali.

👆
FINAL DESIGN
1️⃣2️⃣ Design Kee Xumuri

🎯 Kaayyoo: Barnoota guutuu hojii design tokkoon mirkaneessuu.

📖 Ibsa bal'aa: Amma font haaraa galchitee, filattee fi barruu irratti hojii irra oolchiteetta. Tarkaanfii dhumaa keessatti poster, thumbnail, quote design ykn title design gabaabaa qopheessi.

Font filatame design waliin akka walsimu ilaali. Barruun akka dubbifamu, spacing isaa gaarii akka ta'u, color fi background waliin akka walsimu mirkaneessi.

👆 Maal tuquu qabda? Text settings irraa size, color, shadow, stroke fi effects barbaachisan sirreessi.

❓ Maaliif? Kaayyoon Lesson 2 font galchuu qofa osoo hin taane, font sana design keessatti sirriitti fayyadamuudha.

📍 Bakka: Canvas + Text Customization

⚠️ Hubachiisa: Font baay'ee hin makiin. Design qulqulluu fi dubbifamuu danda'u qopheessi.

✅ Bu'aa: Design xumurame fi screenshot assignmentif qophaa'e argachuu qabda.

🔍 Suuraa tuqi — guddisii ilaali.
