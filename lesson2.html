📝 NOTE GUUTUU — FONT HAARAA PIXELLAB KEESSATTI GALCHUU

1️⃣ Font jechuun maal?

Font jechuun boca fi akkaataa barruun itti mul'atuudha. Barruun tokko font adda addaatiin style adda addaa qabaachuu danda'a.

Fakkeenyaaf font tokko handwriting fakkaachuu danda'a. Kan biraa modern, bold, professional ykn decorative fakkaachuu danda'a.

Design keessatti font filannoon baay'ee barbaachisaa dha. Font sirrii yoo filatte poster, flyer, thumbnail, logo fi social media design kee bareedaa fi professional fakkaata.

2️⃣ Font maaliif barbaachisa?

  • Design kee bareechisa.
  • Ergaa design keessa jiru ifa godha.
  • Brand kee adda baasa.
  • Poster fi Flyer irratti style kenna.
  • Thumbnail nama hawwatu uumuuf gargaara.
  • Barruun akka salphaatti dubbifamu taasisa.
  • Design kee professional fakkeessa.
⚠️ Hubachiisa:
Font baay'ee walitti makuun design kee burjaajessuu danda'a. Yeroo baay'ee design tokko keessatti font 2 ykn 3 caalaa fayyadamuun hin barbaachisu.

3️⃣ TTF fi OTF jechuun maal?

TTF — TrueType Font: format font beekamaa kan app fi computer hedduu irratti hojjetudha.

OTF — OpenType Font: format font ammayyaa kan typography fi amaloota font dabalataa qabaachuu danda'uudha.

PixelLab keessatti font haaraa galchuuf yeroo baay'ee .ttf ykn .otf fayyadamna.

4️⃣ Font eessaa arganna?

Font seera qabeessa ta'een argachuuf websites amanamoo fayyadamuun gaarii dha. Font buufachuu dura license isaa ilaali. Font tokko tokko personal use qofaaf ta'uu danda'a; kan biraa commercial use eeyyamu danda'a.

5️⃣ Font buufannee booda maal goona?

  1. Font kee buufadhu.
  2. Yoo ZIP keessatti dhufe, Extract / Unzip godhi.
  3. Keessa isaa file font kan akka MyFont.ttf ykn MyFont.otf barbaadi.
  4. Font file sana PixelLab keessatti galchuuf qopheessi.
📌 Tartiiba guddaa yaadadhu:
Download → Extract → TTF/OTF → PixelLab → Font → My Fonts → Add → Select → Apply → Design

6️⃣ PixelLab keessatti font galchuu

  1. PixelLab bani.
  2. Text tokko filadhu ykn Text haaraa dabali.
  3. Mallattoo A ykn Text settings seeni.
  4. Font filadhu.
  5. My Fonts seeni.
  6. Mallattoo + ykn Add yoo jiru tuqi.
  7. File Manager irraa font kee barbaadi.
  8. File .ttf ykn .otf filadhu.
  9. Add / Select / Open / OK kan mul'atu tuqi.
  10. My Fonts keessatti font haaraa filadhu.
  11. Barruu kee irratti Apply godhi.

7️⃣ Font haaraan design irratti akkamitti fayyada?

Font galchuun qofa gahaa miti. Fonticha design keessatti sirriitti fayyadamuun barbaachisaa dha.

Title, subtitle fi body text irratti font garaagaraa fayyadamuun ni danda'ama. Garuu readability fi hierarchy eegi.

⚠️ Rakkoolee uumamuu danda'an

  • Fontiin ZIP keessaa hin baafamne ta'uu danda'a.
  • File sun font dhugaa ta'uu dhiisuu danda'a.
  • Extension isaa .ttf ykn .otf ta'uu isaa ilaali.
  • Font file bakka sirrii keessa jiraachuu isaa mirkaneessi.
  • PixelLab cufii irra deebiin bani.
  • Fontiin tokko Android ykn PixelLab version waliin wal hin simne ta'uu danda'a.
  • Font baay'ee fayyadamuun design kee ulfaataa fi burjaajaa gochuu danda'a.

Lesson kana keessatti font haaraa galchuuf jalqaba PixelLab keessa seenuu qabda.

👆 Maal tuqna?
PixelLab icon tuqiitii app bani.

📍 Bakka: PixelLab App

⚠️ Yoo app hin banamne:
App install sirrii ta'uu fi storage bilbila kee ilaali.

✅ Bu'aa:

2️⃣ Text Dabali

🎯 Kaayyoo: Text layer qabaachuu.

📖 Ibsa bal'aa: Font haaraa yaaluuf barruu tokko qabaachuun barbaachisaa dha. Text layer irratti maqaa kee ykn jecha gabaabaa barreessi.

👆 Maal tuqna?
Mallattoo A ykn Text jedhu barbaadiitii tuqi.

❓ Maaliif?
Font haaraa galchinee booda barruu irratti hojii irra oolchuu qabna.

📍 Bakka: PixelLab → Text

⚠️ Yoo Text hin mul'anne:
Menu ykn toolbar keessa ilaali; version app garaagaraa ta'uu danda'a.

✅ Bu'aa:
Canvas irratti barruun tokko mul'achuu qaba.

3️⃣ Text Settings Seeni

🎯 Kaayyoo: Bakka font itti argamu bira ga'uu.

📖 Ibsa bal'aa: Text layer erga filattee booda settings adda addaa argatta. Isaan keessaa Font jedhu barbaadi. Font menu keessatti fontwwan PixelLab duraan qabuu fi My Fonts arguu dandeessa.

👆 Maal tuqna?
Text filadhu → Text settings → Font.

❓ Maaliif?
Font haaraa galchuuf gara Font menu seenuu qabda.

📍 Bakka: Text Controls → Font

⚠️ Yoo hin argamne:
Toolbar gara bitaa ykn mirgaatti harkisi.

✅ Bu'aa:
Font menu siif banamuu qaba.

4️⃣ Font Menu Filadhu

🎯 Kaayyoo: My Fonts bakka jedhu argachuu.

📖 Ibsa bal'aa: Font menu keessatti PixelLab fontwwan duraan qabdu agarsiisa. As keessatti bakka My Fonts ykn Custom Fonts fakkaatu barbaadi. Kun bakka font mataa keetii itti galchituudha.

👆 Maal tuqna?
Font menu keessatti My Fonts ykn Custom Fonts tuqi.

❓ Maaliif?
Font haaraa bilbila irraa galchuuf bakka addaa kana fayyadamna.

📍 Bakka: Font Menu → My Fonts

⚠️ Yoo hin argamne:
Font menu gadi fi oli sochoosi. Version PixelLab tokko tokko maqaa menu garaagaraa qaba.

✅ Bu'aa:
My Fonts page ykn font import page siif banamuu qaba.

5️⃣ My Fonts Seeni

🎯 Kaayyoo: Font dhuunfaa galchuuf bakka sirrii argachuu.

📖 Ibsa bal'aa: My Fonts jechuun bakka font ati mataa keetiin galchite itti kuufamuudha. As keessatti font haaraa galchuuf mallattoo Add ykn + barbaadi.

👆 Maal tuqna?
My Fonts keessatti +, Add ykn button font dabaluuf jiru barbaadi.

❓ Maaliif?
PixelLabiin font haaraa akka barbaaduuf import process jalqaba.

📍 Bakka: My Fonts → Add / +

⚠️ Yoo hin argamne:
Version PixelLab garaagaraa ta'uu danda'a. Folder ykn plus icon barbaadi.

✅ Bu'aa:
File Manager ykn font selection page banamuu qaba.

6️⃣ Add Font Filadhu

🎯 Kaayyoo: Font file gara PixelLabitti dabaluuf.

📖 Ibsa bal'aa: My Fonts keessaa Add ykn folder-plus tuqxu. Sana booda PixelLab bilbila kee keessaa font barbaada. Font kee yeroo baay'ee Downloads folder keessa jira.

👆 Maal tuqna?
Add ykn folder-plus button tuqi.

❓ Maaliif?
Font file bilbila keessa jiru filachuuf.

📍 Bakka: My Fonts → Add / Folder

⚠️ Yoo font hin argamne:
Downloads, Documents ykn folder ati font itti kuufte ilaali.

✅ Bu'aa:
File Manager ykn File Picker banamuu qaba.

7️⃣ File Manager Keessa Seeni

🎯 Kaayyoo: Font file kee bilbila keessaa argachuu.

📖 Ibsa bal'aa: File Manager banamee booda folder font kee itti buufatte barbaadi. Yeroo baay'ee Downloads folder keessa jira. Yoo ZIP irraa baafatte, folder ati itti Extract goote keessa ilaali.

👆 Maal tuqna?
Downloads ykn folder font kee itti kuufame tuqi.

❓ Maaliif?
PixelLabiin font file mataa isaa argachuu qaba.

📍 Bakka: File Manager → Downloads / Fonts

⚠️ Hubadhu:
ZIP/RAR file mataa isaa hin filatin. Jalqaba Extract/Unzip godhi.

✅ Bu'aa:
Tarree font files kee arguu qabda.

8️⃣ Font File Sirrii Filadhu

🎯 Kaayyoo: Font file sirrii filachuu.

📖 Ibsa bal'aa: Font file dhuma isaa irratti .ttf ykn .otf qabaachuu danda'a. Fakkeenya: MyFont.ttf ykn MyFont.otf.

👆 Maal tuqna?
File .ttf ykn .otf tuqi.

❓ Maaliif?
PixelLabiin font file sirrii akka argatuuf.

📍 Bakka: File Manager → .TTF / .OTF

⚠️ Hin filatin:
JPG, PNG, ZIP ykn file design. Font file qofa filadhu.

✅ Bu'aa:
Font file filatamee import process itti fufa.

9️⃣ Import / Add Godhi

🎯 Kaayyoo: Font file gara PixelLabitti galchuu.

📖 Ibsa bal'aa: Font file erga filattee booda PixelLab version kee irratti Add, Select, Open, OK ykn Add Directory fakkaatu arguu dandeessa.

Maqaan button garaagaruu danda'a; garuu hojii isaa tokko: fonticha gara PixelLabitti galchuu.

👆 Maal tuqna?
Add / Select / Open / OK kan mul'atu tuqi.

❓ Maaliif?
Font file akka PixelLab keessatti galmaa'uuf.

📍 Bakka: Font Import Dialog

⚠️ Yoo hin milkoofne:
Font file sirrii ta'uu isaa fi Extract gochuu kee mirkaneessi.

✅ Bu'aa:
Fontiin My Fonts keessatti mul'achuu qaba.

🔟 Font Haaraa Filadhu

🎯 Kaayyoo: Font import godhame hojii irra oolchuu.

📖 Ibsa bal'aa: Font galfamee booda My Fonts keessatti maqaa font haaraa barbaadi. Fonticha tuqi. Yeroo tuqxu barruun kee fonticha fayyadamuun jijjiiramuu qaba.

👆 Maal tuqna?
Maqaa font haaraa tarree My Fonts keessaa tuqi.

❓ Maaliif?
Import gochuun qofti gahaa miti. Fonticha barruu irratti Apply gochuu qabda.

📍 Bakka: My Fonts → Font List

⚠️ Yoo hin mul'anne:
PixelLab cufii irra deebiin bani ykn fonticha import irra deebi'i.

✅ Bu'aa:
Barruun kee font haaraan mul'achuu qaba.

1️⃣1️⃣ Barruu Irratti Apply Godhi

🎯 Kaayyoo: Font haaraa design irratti sirriitti fayyadamuu.

📖 Ibsa bal'aa: Font tokko design irratti bareedaa fakkaachuu qofa osoo hin taane dubbifamuu qaba. Maqaa kee ykn sentence gabaabaa itti barreessi. Size, color, spacing fi effects isaa sirreessi.

👆 Maal tuqna?
Text filadhu → Font → Font haaraa filadhu → Apply.

❓ Maaliif?
Font tokko title irratti gaarii ta'uu danda'a, subtitle ykn body text irratti garuu dubbifamuu dhiisuu danda'a.

📍 Bakka: Canvas → Text Layer → Font Controls

⚠️ Hubachiisa:
Font decorative baay'ee ta'e barruu dheeraa irratti hin fayyadamin.

✅ Bu'aa:
Barruun kee font haaraan ifatti mul'achuu qaba.

1️⃣2️⃣ Design Kee Xumuri

🎯 Kaayyoo: Barnoota guutuu hojii design tokkoon mirkaneessuu.

📖 Ibsa bal'aa: Amma font haaraa galchitee, filattee fi barruu irratti hojii irra oolchiteetta. Tarkaanfii dhumaa keessatti poster, thumbnail, quote design ykn title design gabaabaa qopheessi.

Font filatame design waliin akka walsimu ilaali. Barruun akka dubbifamu, spacing isaa gaarii akka ta'u, color fi background waliin akka walsimu mirkaneessi.

👆 Maal tuqna?
Text settings irraa size, color, shadow, stroke fi effects barbaachisan sirreessi.

❓ Maaliif?
Kaayyoon Lesson 2 font galchuu qofa osoo hin taane, font sana design keessatti sirriitti fayyadamuudha.

📍 Bakka: Canvas + Text Customization

⚠️ Hubachiisa:
Font baay'ee hin makiin. Design qulqulluu fi dubbifamuu danda'u qopheessi.

✅ Bu'aa:
Design xumurame fi screenshot assignmentif qophaa'e argachuu qabda.
