🔤 Font jechuun maal?

Font jechuun bifa barruun ittiin barreeffamuudha. Fakkeenyaaf, font tokko barruu nama hawwatu, kan biraa ammoo barruu professional fakkaatu qaba.

📌 TTF

TTF jechuun TrueType Font. Font baay'ee application keessatti fayyadamuuf mijataadha.

📌 OTF

OTF jechuun OpenType Font. Innis font qulqullina gaarii qabuudha.

💡 Note: PixelLab keessatti TTF fi OTF font hedduu fayyadamuun ni danda'ama.

🖼️ Visual Guide — Tarkaanfiiwwan 14

Suuraa tokko tokko irratti cuqaasi — suuraan guddatee siif mul'ata.

1

PixelLab bani

Application PixelLab bilbili. Fuula hojii isaa irraa jalqabi.

💡 Note: PixelLab sirriitti install ta'uu mirkaneessi.
2

New Text filadhu

Mallattoo A ykn Text cuqaasi. Sana booda New Text filadhu.

💡 Note: Barruu haaraa ittiin galchitu.
3

Text menu bani

Barruu filadhu. Sana booda menu barruu keessaa Font barbaadi.

💡 Note: Font jijjiiruuf menu kana fayyadamna.
4

Font bani

Menu Font keessa seeni.

💡 Note: As keessatti font PixelLab keessa jiran ni argita.
5

My Fonts filadhu

Font menu keessatti My Fonts jedhu filadhu.

💡 Note: Font ofii keetii itti galchitu.
6

+ / Add Font

Mallattoo + cuqaasi. Kun font haaraa galchuuf si gargaara.

💡 Note: File font barbaaduuf + fayyadami.
7

Downloads bani

Font download goote keessaa folder Downloads bani.

💡 Note: Font yeroo baay'ee Downloads keessa gala.
8

ZIP extract godhi

Yoo font kee ZIP ta'e, Extract godhi.

💡 Note: PixelLab keessatti ZIP osoo hin taane TTF/OTF filadhu.
9

TTF ykn OTF barbaadi

Folder extract godhame keessaa .ttf ykn .otf file barbaadi.

💡 Note: Isaan lamaan font files dha.
10

Font file filadhu

TTF ykn OTF file irratti cuqaasi.

💡 Note: Font sirrii filachuu kee mirkaneessi.
11

Add Selected

Font filattee booda Add Selected cuqaasi.

💡 Note: Font gara My Fonts keessatti galcha.
12

Font haaraa filadhu

Amma font ati galchite My Fonts keessatti mul'ata. Isa filadhu.

💡 Note: Font haaraan barruu kee irratti hojjeta.
13

Save / Export

Hojii kee erga xumurte booda Save as Image filadhu.

💡 Note: Assignment kee image ta'ee phone kee irratti kuufama.
14

Quality filadhu

Export yeroo gootu quality gaarii filadhu.

💡 Note: Poster qulqullina gaarii qabaachuuf resolution gaarii fayyadami.
