🔤 Font jechuun maal?

Font jechuun bifa qubee fi barruun ittiin mul'atuudha. Fakkeenyaaf, qubee tokko font adda addaatiin yoo barreeffame, bifni isaa ni jijjiirama.

  • TTF = TrueType Font
  • OTF = OpenType Font
  • Font sirrii filachuun design kee professional akka fakkaatu gargaara.
  • Font baay'ee walitti makuun design akka jeequ danda'a; kanaaf font muraasa sirriitti filadhu.
💡 Gorsa: Font tokko download gootee booda maqaa faayilaa isaa ilaali. Yoo dhuma irratti .ttf ykn .otf qabaate, font ta'uu isaa beekuu dandeessa.

Hiika: Project haaraa banachuun canvas haaraa argamsiisa. As irratti poster, social media design ykn assignment kee hojjetta.

3

📝 Text Filadhu

GIF
Hiika: Font jijjiiruuf dura text qabaachuu qabda. Text irratti cuqaasuun text tool fi editing options argatta.
📍 Bakka argama: Toolbar gubbaa → mallattoo Tt/Text.
4

🔤 Font Menu Bani

GIF
Hiika: Font menu keessatti fontota PixelLab keessa jiran argita. Asuma irraa gara My Fonts deemtee font ati ofii keetiin galchite argatta.
📍 Bakka argama: Text filadhu → Toolbar gubbaa → Aa/Font.
5

📚 My Fonts Filadhu

GIF
Hiika: My Fonts jechuun bakka font ati alaa irraa fiddee PixelLab keessa galchite itti kuufamuudha. Font haaraa kee yeroo booda as irraa deebitee filachuu dandeessa.
📍 Bakka argama: Font menu → tab/button MY FONTS.
6

➕ Add Font Cuqaasi

GIF
Hiika: Add Font jechuun faayila font bilbila keessaa filachuuf button dha. Isa cuqaasuun file manager banama.
📍 Bakka argama: My Fonts → mallattoo + ykn Add Font.
7

📁 File Manager Bani

GIF
Hiika: File manager keessatti Downloads, Documents ykn folder ati font itti kuufte barbaadi. Font download goote yoo Downloads keessa jiraate, yeroo baay'ee achitti argatta.
📍 Bakka argama: Add Font → File Manager → Downloads ykn folder font itti kuufame.
8

🔎 Font Barbaadi

GIF
Hiika: Faayila font kee barbaadi. Maqaan isaa yeroo baay'ee .ttf ykn .otf tiin xumurama. Faayila sirrii filachuu kee mirkaneessi.
📍 Bakka argama: Downloads/folder font → faayila .ttf ykn .otf.
9

📥 Import Godhi

GIF
Hiika: Faayila font sirrii erga filattee booda IMPORT cuqaasi. PixelLab font sana gara My Fonts keessa galcha.
📍 Bakka argama: Import screen → button IMPORT gadii.
10

🔤 Font Haaraa Filadhu

GIF
Hiika: Amma font haaraan My Fonts keessatti mul'ata. Isa filachuun text kee font haaraan akka barreeffamu taasisa.
📍 Bakka argama: Font menu → My Fonts → maqaa font haaraa.
11

🎨 Design Irratti Fayyadami

GIF
Hiika: Font qofa galchuun hin ga'u. Font sana design keessatti bakka sirrii irratti fayyadami. Title, subtitle fi barruu gargaaraa irratti hierarchy uumi.
📍 Bakka argama: Text tool → text kee filadhu → Font → font haaraa filadhu.
12

📸 Screenshot Godhi

GIF
Hiika: Hojii kee xumursi. Erga design qulqulluu ta'e booda screenshot godhi. Screenshot kun assignment kee akka ragaa ta'uuf barbaachisa.
📍 Bakka argama: Gallery/Photos keessatti screenshot kee argatta; achii assignment irratti submit godhi.

📝 ASSIGNMENT — Lesson 2

Amma waan baratte hojiitti jijjiiri. Fakkeenya suuraa armaan gadii copy qofa hin godhin. Yaada mataa keetiin design haaraa uumi.

✅ Font TTF ykn OTF tokko barbaadi.
✅ PixelLab keessatti import godhi.
✅ Font haaraa title irratti fayyadami.
✅ Subtitle/barruu gabaabaa dabali.
✅ Color fi spacing sirreessi.
✅ Design xumuraa screenshot godhi.
