🎬 Video Lesson 3

📝 Note: Video kana keessatti PixelLab fayyadamuun logo design akkamitti akka jalqabamu ilaalla. Tarkaanfii hunda suuta hordofi. Logo hojjechuun dura yaada fi karoora qabaachuun barbaachisaadha.

1️⃣ Logo jechuun maal?

Logo jechuun mallattoo ykn fakkii brand tokko bakka bu'uudha. Inni eenyummaa hojii tokkoo nama beeksisa.

Fakkeenya:

  • 🎨 KENA DESIGN Logo
  • 🏢 Business Logo
  • ▶️ YouTube Channel Logo
  • 📷 Studio Logo
📝 Note Bal'aa: Logo gaariin salphaa, yaadatamaa fi qulqulluu ta'uu qaba. Namni yeroo jalqaba ilaaluun: - Maqaa brand sana hubachuu qaba. - Hiika isaa beekuu qaba. - Salphatti yaadatamuu qaba.

2️⃣ Gosoota Logo

📝 1. Text Logo

Text Logo jechuun maqaa brand qofa fayyadamuun logo hojjechuudha. Logo akkanaa keessatti font fi style barreeffamaa baay'ee murteessaadha.

📝 Note: Text Logo keessatti font filachuun baay'ee barbaachisaadha. Font: ✅ dubbifamuu danda'u ✅ bareedaa ta'e ✅ brand waliin wal simatu ta'uu qaba.

🎨 2. Icon Logo

Icon Logo jechuun fakkii ykn mallattoo tokko fayyadamuun logo hojjechuudha. Fakkeenya: - Camera icon (Studio) - Computer icon (Technology) - Brush icon (Design)

📝 Note: Icon filattu hojii ykn brand kee waliin wal qabachuu qaba. Icon sirrii filachuun namni logo ilaaluun hojii kee akka hubatu gargaara.

🔰 3. Combination Logo

Combination Logo jechuun Text fi Icon walitti makuun logo uumuu dha. Kun yeroo baay'ee business fi company keessatti fayyadama.

📝 Note: Combination Logo keessatti:
✅ Maqaa brand
✅ Icon
✅ Color wal madaalanii hojjechuu qabu.

3️⃣ PixelLab keessatti Logo Hojjechuu

Amma PixelLab fayyadamuun logo professional salphaa akkamitti akka hojjetamu ilaalla. Tarkaanfiiwwan armaan gadii hordofi.

📌 Tarkaanfii 1: PixelLab Bani

Jalqaba PixelLab app kee bani. Erga bannee booda hojii haaraa jalqabuuf New Project filadhu.

📝 Note: Logo hojjechuu dura:
- Maqaa brand kee murteessi
- Style isaa yaadi
- Color filadhu Kana booda design jalqabi.

📌 Tarkaanfii 2: Background Filadhu

Background logo kee filadhu. Background adii, gurraacha ykn transparent fayyadamuun ni danda'ama.

📝 Note: Background baay'ee jeequmsa qabu hin fayyadamin. Logo ifa fi qulqulluu ta'uu qaba.

📌 Tarkaanfii 3: Text Dabaluu

Text tool keessaa maqaa brand kee barreessi. Fakkeenya:

🎨 KENA DESIGN

📝 Note: Text keessatti:
✅ Font sirrii filadhu
✅ Size sirreessi
✅ Bakka isaa sirreessi

📌 Tarkaanfii 4: Font Jijjiruu

Font filannoo keessaa style brand kee waliin wal simatu filadhu.

📝 Note: Font baay'ee hedduu walitti hin makiin. Logo tokko keessatti font 1 ykn 2 fayyadamuun gaarii dha.

📌 Tarkaanfii 5: Shape Dabaluu

PixelLab keessatti Shape fayyadamuun logo kee caalaatti bareechisuu dandeessa. Shape jechuun boca adda addaa kan akka circle, square fi kkf dha.

📝 Note: Shape yeroo fayyadamtu:
✅ Baay'ee hin guutin
✅ Logo waliin wal simsiisi
✅ Salphaa taasisuuf yaali

📌 Tarkaanfii 6: Icon Dabaluu

Icon tokko logo kee keessatti dabaluun hiika dabalataa kenna. Fakkeenya:

🎨 Design → Brush ykn Pencil Icon
📷 Photography → Camera Icon
💻 Technology → Computer Icon

📝 Note: Icon filattu hojii kee ibsuu qaba. Icon qofa bareedinaaf osoo hin taane ergaa dabarsuuf fayyada.

📌 Tarkaanfii 7: Color Sirreessuu

Color logo keessatti miira fi eenyummaa brand ibsa. PixelLab keessatti color filannoo keessaa color sirrii filadhu.

  • 🟢 Green → Guddina fi nageenya
  • 🔵 Blue → Amanamummaa fi professional
  • 🔴 Red → Humna fi xiyyeeffannoo
  • ⚫ Black → Elegance fi cimina
  • ⚪ White → Qulqullina
📝 Note Bal'aa: Logo tokko keessatti color baay'ee hedduu fayyadamuun nama jeequu danda'a. Color 2 ykn 3 qofa fayyadamuun professional fakkaata.

✨ Effect fi Shadow Dabaluu

PixelLab keessatti Shadow, Stroke fi Effect fayyadamuun text fi icon kee ifa gochuu dandeessa.

🌑 Shadow

Shadow jechuun gaaddisa text ykn icon jala jiruudha. Inni logo kee gara professional fakkeessa.

⭕ Stroke

Stroke jechuun daangaa ykn sarara naannoo text jiruudha. Text akka ifatti mul'atu gargaara.

📝 Note: Effect baay'ee hin dabalin. Logo gaariin:
✅ Qulqulluu
✅ Salphaa
✅ Hubatamaa ta'uu qaba.
