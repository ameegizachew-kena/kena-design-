📱 KENA DESIGN — PixelLab Logo Design Visual Guide

Suuraawwan armaan gadiitti PixelLab keessatti Logo Design hojjechuuf tarkaanfiiwwan ijoo agarsiifamu. Suuraa tokko tuquun guddisuu dandeessa.

1️⃣ PixelLab Banuu

PixelLab baniitii project haaraa jalqabi. Bakka hojii logo itti hojjetamu qopheessi.

2️⃣ Canvas Qopheessuu

Size fi qulqullina canvas sirreessi. Logo qulqullina qabu hojjechuuf barbaachisaa dha.

3️⃣ Background Filachuu

Background logo keetiif mijatu filadhu. Halluu sirrii fayyadamuun design bareessa.

4️⃣ Text Dabaluun

Maqaa brand kee barreessi. Size fi bakka text sirreessi.

5️⃣ Font Filachuu

Font dubbifamuu danda'u fi professional filadhu. Font baay'ee walitti hin makiin.

6️⃣ Color Qindeessuu

Halluu 2 ykn 3 qofa fayyadamuun logo qulqulluu uumi.

7️⃣ Icon Dabaluun

Icon hojii brand kee ibsu itti dabali. Text waliin wal simsiisi.

8️⃣ Shape Fayyadamuu

Shape salphaa fayyadamuun logo kee bareechisi.

9️⃣ Shadow fi Effect

Shadow fi Stroke xiqqoo fayyadamuun text adda baasi.

🔟 Logo Sirreessuu

Text, icon fi color wal madaalchisi. Logo kee ilaali.

1️⃣1️⃣ Export PNG

1️⃣2️⃣ Assignment Hojjechuu

🎨 Color Sirrii Filachuu

Halluun logo keessatti ergaa addaa qaba. Halluu sirrii filachuun brand kee cimaa godha.

  • 🟢 Green: guddina, uumama fi abdii.
  • 🔵 Blue: amanamummaa fi tasgabbii.
  • 🔴 Red: humna fi xiyyeeffannoo.
  • ⚫ Black: cimina fi professional.
  • ⚪ White: qulqullina fi salphina.
Gorsa:
Logo tokko keessatti halluu baay'ee hin fayyadamin. Jalqabaaf halluu 2 ykn 3 qofa filachuun gaarii dha.

🔤 Font Filachuu

Font jechuun bifa qubee (barreeffamaa) ti. Font sirrii filachuun logo kee professional taasisa.

  • ✅ Font dubbifamuu danda'u filadhu.
  • ✅ Font baay'ee walitti hin makiin.
  • ✅ Maqaa brand waliin wal simsiisi.
  • ✅ Font salphaa yeroo baay'ee caala.
Fakkeenya Font:
Modern: Brand haaraa fi technology.
Bold: Humna fi jabina agarsiisa.
Simple: Salphina fi qulqullina agarsiisa.

✨ Shadow, Stroke fi Effect

🌑 Shadow

Shadow jechuun gaaddisa text ykn object duuba jiru. Text akka ifatti mul'atu gargaara.

⭕ Stroke

Stroke jechuun daangaa ykn sarara naannoo text jiru.

💡 Opacity

Opacity jechuun wanti tokko hammam ifa ykn dukkanaa'aa akka mul'atu to'achuu dha.

Effect baay'ee hin dabalin. Logo salphaa fi qulqulluun yeroo baay'ee caala.
