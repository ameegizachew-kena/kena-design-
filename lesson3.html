📘 Kaayyoo Lesson 3

Barnoota kana booda barataan PixelLab keessatti Logo Design jalqabuu, mallattoo brand uumuu fi design isaa qulqullinaan save gochuu ni danda'a.

  • Logo jechuun maal akka ta'e ni beeka.
  • Gosoota logo adda baasuu ni danda'a.
  • Text, Font, Icon fi Color fayyadamuu ni barata.
  • Shape, Shadow fi Stroke fayyadamuu ni barata.
  • Logo PNG ta'een save gochuu ni danda'a.

📚 Ibsa Bal'aa Video Lesson 3

Barnoota kana keessatti PixelLab fayyadamuun Logo Design akkamitti akka jalqabnu ni baranna. Logo jechuun mallattoo, fakkii ykn barreeffama maqaa brand, dhaabbata, daldalaa ykn hojii tokko bakka bu'uudha.

🎯 1. Kaayyoo Logo Design

Kaayyoon logo design maqaa brand tokko salphaatti beekamuu fi yaadatamuu gochuudha. Logo gaariin ergaa hojii kee dabarsa. Fakkeenyaaf, logo KENA DESIGN keessatti mallattoo qalama ykn meeshaa design fayyadamuun hojii design ibsuu dandeessa.

📱 2. PixelLab Banuu

Jalqaba bilbila kee irratti PixelLab bani. Project haaraa jalqabi. Bakka hojii kee qopheessi. Logo kee maalif akka hojjetu murteessi: Business, YouTube, Photography, App ykn Design Company.

🖼️ 3. Canvas Qopheessuu

Canvas jechuun bakka design itti hojjetamuudha. Size hojii keetiif mijatu filadhu. Logo keessatti wantoonni barbaachisoo ta'an qofa akka mul'atan qindeessi. Maqaa fi icon kee bakka wal madaalu irratti kaa'i.

🎨 4. Background Filachuu

Background jechuun duubbee logo keetiiti. Halluu hojii keetiif mijatu filadhu. Logo kee background ifaa fi dukkanaa'aa irratti yeroo ilaalamu dubbifamuu akka danda'u mirkaneessi.

🔤 5. Text fi Font

Text menu fayyadamuun maqaa brand kee barreessi. Font dubbifamuu danda'u filadhu. Font baay'ee walitti makuun design kee hin dhiphisin. Maqaan brand kee ifatti mul'achuu qaba.

🌈 6. Color Sirrii Filachuu

Jalqaba halluu lama ykn sadii fayyadami. Green guddina, blue amanamummaa, black cimina, white immoo qulqullina agarsiisuu danda'a. Halluuwwan wal simatan filadhu.

🧩 7. Icon fi Shape

Icon jechuun mallattoo hojii brand kee ibsuudha. Photography logo keessatti mallattoo camera fayyadamuu dandeessa. Shape salphaa itti dabaluun logo kee bareechuu dandeessa. Garuu wantoota hin barbaachifne baay'inaan hin dabalin.

✨ 8. Shadow, Stroke fi Effect

Shadow jechuun gaaddisa object ykn text ti. Stroke jechuun daangaa text ykn object naannoo isaa jiru. Effect fayyadamuun design kee bareechuu dandeessa. Garuu effect baay'ee fayyadamuun logo kee hin dhiphisin.

✅ 9. Logo Sirreessuu

Erga text, font, icon fi halluu filattee booda, wantoota kana wal madaalchisi. Maqaan brand kee ifatti dubbifamuu qaba. Logo kee salphaa, qulqulluu fi yaadatamuu danda'u taasisuuf irra deebi'ii ilaali.

📤 10. Logo PNG Ta'een Save Gochuu

Design kee erga xumurte booda filannoo Export ykn Save as Image fayyadami. PNG filadhu. Yoo background iftoomina qabu barbaadde, PixelLab keessatti filannoo transparent background jiru ilaali. Sana booda logo kee bilbila irratti save godhi.

📝 11. Assignment

Waan video keessatti baratte fayyadamuun logo brand mataa kee hojjedhu. Maqaa, font, icon fi halluu sirnaan qindeessi. Hojii kee xumuraa PNG ta'een save godhi.

🎨 Color Sirrii Filachuu

Halluun logo keessatti ergaa addaa qaba. Halluu sirrii filachuun brand kee salphaatti akka beekamu gargaara.

  • 🟢 Green: guddina, uumama fi abdii.
  • 🔵 Blue: amanamummaa fi tasgabbii.
  • 🔴 Red: humna fi xiyyeeffannoo.
  • ⚫ Black: cimina fi professional.
  • ⚪ White: qulqullina fi salphina.
Gorsa: Logo tokko keessatti halluu baay'ee hin fayyadamin. Jalqabaaf halluu lama ykn sadii filachuun gaarii dha.

🔤 Font Filachuu

Font jechuun bifa qubee barreeffamaa ti. Font sirrii filachuun logo kee professional taasisa.

  • ✅ Font dubbifamuu danda'u filadhu.
  • ✅ Font baay'ee walitti hin makiin.
  • ✅ Maqaa brand waliin wal simsiisi.
  • ✅ Font salphaa yeroo baay'ee caala.
Modern: Brand haaraa fi technology.
Bold: Humna fi jabina.
Simple: Salphina fi qulqullina.

✨ Shadow, Stroke fi Effect

🌑 Shadow

Shadow jechuun gaaddisa text ykn object duuba jiruudha.

⭕ Stroke

Stroke jechuun daangaa ykn sarara naannoo text jiruudha.

💡 Opacity

Opacity jechuun wanti tokko hammam ifa ykn dukkanaa'aa akka mul'atu to'achuudha.

Effect baay'ee hin dabalin. Logo salphaa fi qulqulluun yeroo baay'ee caala.
